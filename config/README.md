# 全局配置入口

## 目录用途

`config/` 用于登记跨多个软件包共享、需要在运行时统一选择的配置。当前只有本 README 是有意的：P2 的 H60 配置尚未实现和验收，因此不能为了让目录“看起来完整”而复制一份未经验证的 YAML。

H60 动力运行 YAML 尚未实现和验收。上一 STM32/JGB 小车的配置用于旧软件复现，不作为当前默认值。

## H60 配置建立条件

H60 迁移时，应先在 ROS2 bringup 包内形成可安装的真实运行配置，并完成：

1. 协议版本、设备路径和 UART 周期；
2. STOP/DISARM、显式 ARM、命令超时和故障行为；
3. 四路方向、计数边沿、CPR、轮径、轮距和速度/加速度限制；
4. H60 PC0 VIN ADC 多点校准版本；
5. 无动力、架空和落地对应验收。

只有出现两个或以上软件包确实需要共享同一配置，或者需要稳定的仓库级配置选择入口时，才在本目录增加文件。不得把同一 YAML 同时复制到两个位置手工维护。

## 更新机制

- 配置值的改变必须来自真实实现、标定或测试，不从 README 自动生成。
- 每次更新同时记录来源、单位、硬件/固件版本、适用模式、验证状态和回滚值。
- P2 的关键参数选择、证据和验证结果应随实现一并记录。
- 配置从“候选”变为“默认”前必须通过对应阶段门；未实测值不得写成冻结事实。
- 本 README 在目录职责、事实源位置或更新规则变化时人工受控更新，没有定时自动改写机制。
