# v1.1.3｜Nano 与 H60 架空控制验证

## 硬件与测试边界

架空配置为 Jetson Orin Nano 8GB、OpenCTR H60 V3.7、四台 MC520P56 减速电机和真实无线手柄。手柄接收器连接 Nano，Nano 通过 USB-COM 与 H60 通信。四轮离地，固件使用隔离工程构建 28R2。ROS 2 模式与仲裁验证在隔离的软件试验中完成。

## 验证结果

| 验证范围 | 观察 | 结论 |
| --- | --- | --- |
| Nano 上的 ROS 2 运行 | 六个包构建完成，生成模式消息与服务，五个节点启动和正常退出。17 段覆盖待机、显式手动、新中性与新输入、软件停车锁止、模式权重启及消息超时。 | 软件替身场景通过。 |
| 四轮架空运动 | 用真实手柄观察前进、后退及左右方向。编码器和协议记录采到了轮端响应。松使能键时发出 STOP 并观察到停轮。 | 当前架空配置通过对应方向与普通停车。 |
| 无线手柄关机与重新使能 | 手柄电源关闭并下线，协议记录出现 STOP，操作者观察四轮停止。恢复连接和清锁后，新的会话、输入和显式使能可恢复控制。 | 当前架空配置通过关机停车和显式恢复。 |
| 开机前持键重连 | 重连后的第一个健康输入已处于持使能键和前推状态。停车后没有第二次 ARM 或非零轮目标，操作者观察四轮保持静止。 | 当前架空配置通过持键重连保护。 |
| 落地后续观察 | 旧轮组完成短直行。轻左弧试验中，实际左右轮速差比目标小，车身几乎直行。 | 轻弧未达目标。新支架和新电机的带载效果待测。 |

数字记录中的 STOP 时间指命令与协议事件。物理停轮依据操作者观察，未测得触发到停车的精确时延或距离。新会话恢复亦未覆盖所有可能的无线断开形式。

## 发布源码复核

- 公开 ROS 2 运行源码与实测冻结源码核对一致。公开配置移除了内部编号注释，运动锁及参数值保持原样。
- 公开候选通过 72 项 ROS 2 单元、替身和启动契约检查。H60 默认构建、宿主机测试及诊断隔离检查通过。
- 使用 GNU Tools for STM32 14.3.rel1（GCC 14.3.1），按[固件说明](../firmware/h60_safe_control/README.md)复编出的 28R2 固件，与实测制品逐字节一致。BIN 长度 12,012 字节，SHA-256 为 `1d03e39d628a4cf32c1e698a30120fc6b2bbd0a842887f58d7f77678ba873f5e`。

P2 尚未通过阶段验收。生产控制、轮端参数、里程计、落地转向和整车系统验收留待后续工程。
