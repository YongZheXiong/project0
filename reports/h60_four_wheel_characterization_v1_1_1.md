# H60 + MC520 四轮单轮运动表征报告（v1.1.1）

## 目的与范围

本报告汇总 Project0 在 P2 阶段取得的四轮单轮受限表征，用于冻结轮位与 H60 端口之间的物理方向、原始编码器符号、工程 CPR 和停车证据。测试均为单轮架空、短时、受控条件；没有执行四轮组合或落地运动。

后轮使用两根临时 `20 cm` 原厂线完成方向与 CPR 表征。该配置可以支持本报告的单轮结论，但不能替代最终长度线束、永久固定、应力释放或整车回归。

## 表征结果

| 轮位 / 端口 | plus 物理方向 / 净计数 | minus 物理方向 / 净计数 | 五圈样本 × 2 | 工程 CPR / 跨度 |
| --- | --- | --- | --- | --- |
| 右前 / MA | 向后 / `-175` | 向前 / `+193` | `+14611 / +14646` | `2926 / 0.2393%` |
| 左前 / MB | 向前 / `-113` | 向后 / `+211` | `-14614 / -14612` | `2923 / 0.0137%` |
| 右后 / MC | 向后 / `-37` | 向前 / `+225` | `+14626 / +14662` | `2929 / 0.2458%` |
| 左后 / MD | 向前 / `-138`，停位复样 `-112` | 向后 / `+114` | `-14618 / -14605` | `2922 / 0.0890%` |

左前 plus 的 `-113` 是成功样本；同一 `50‰` 请求曾有一次未起转且净计数为 `+1`，轮位调整后才取得成功结果。该失败被保留为起转可靠性与负载余量的限制。

## 方法与判据

- 方向样本只驱动一个 H60 端口，观察目标轮实际方向，同时检查目标口计数符号与非目标口是否保持不变。
- CPR 样本在零发送状态下手转目标轮五圈，每轮取两次样本；工程 CPR 由五圈净计数换算并取中值，再给出建议整数。
- 两次 CPR 的跨度按两次样本差异相对其中值计算；四轮结果均小于 `0.25%`。
- 受限停车证据包括主机 STOP/失能、末端零增量和实际停轮观察。它只覆盖相应单轮、短时架空条件。

## 可复用结论

- 端口和轮位的原始方向/符号关系可作为最终坐标归一化与参数集成的输入。
- 四个工程 CPR 建议值可作为最终配置复核的候选值：MA=`2926`、MB=`2923`、MC=`2929`、MD=`2922`。
- 已完成的单轮方向与 CPR 无需在相同配置下无意义重复；配置改变后仍需有针对性的回归。

## 未关闭项

- 最终长度线束、永久固定、应力释放与最终 H60 端口占用回归。
- 四轮架空前进/后退、统一 STOP、链路丢失和故障处置。
- 带载、低电量、热、长时、PWM/电流波形及最终参数集成。
- H2/H3/H5 总门仍为 PARTIAL，H6 尚未通过；不能从本报告推出 P2 完成或落地运动资格。
