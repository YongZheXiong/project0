# 迭代一风险登记

> 文档状态：公开版 P2 风险登记基线
> 文件定位：本文记录 Project0 迭代一公开可说明的主要工程风险和缓解方向，不包含内部治理过程和私人记录。

---

## 1. 当前主要风险

| 风险项 | 等级 | 承接阶段 | 影响 | 缓解方向 |
| --- | --- | --- | --- | --- |
| 到货验收已闭环后的实物复查 | 低 | P2 | 具体物料在装配中仍可能暴露尺寸、固定或端接问题。 | P1 到货验收已完成；P2 中按逐层装配继续做实物复查和问题登记。 |
| 三层底盘或固定件实物偏差 | 高 | P2 | 可能影响机械装配、传感器安装和线束空间。 | 装配前做孔位、毛刺、平整度和干涉检查。 |
| 线束压接和端子匹配不可靠 | 高 | P2 | 可能造成断电、短路、通信不稳或运动异常。 | 压接后做拉力、通断、极性和标识检查。 |
| 电源与急停链路复验 | 中 | P2 | 线束或端子变化可能破坏已验证的安全边界。 | 急停只切动力支路的基础实测已通过；后续继续检查固定、防拉扯和温升。 |
| STM32 下载 / 调试路径回归风险 | 低 | P2 | 工具配置变化可能影响后续烧录效率。 | CMSIS-DAP / OpenOCD 路径已通过多轮测试；后续保留配置记录并按需复验。 |
| STM32 控制板 3.3V 供电故障 | 高 | P2 | 原控制板无法继续完成 SWD、UART、编码器和底盘控制。 | 原板保持隔离；替换板按 5V、3.3V、RESET、SWD 和 USART3 顺序验收。 |
| Orin NX 与 STM32 UART 闭环风险 | 高 | P2 | 上下位机控制闭环可能无法成立。 | 替换板验收后先做串口最小收发，再扩展协议帧和异常停车。 |
| 基础运动控制不稳定 | 高 | P2 | P3 无法安全遥控采集传感器数据。 | 已完成悬空单电机、同侧和四轮短脉冲验证；后续继续完成急停、编码器、UART 和落地低速运动。 |
| 传感器驱动与系统兼容风险 | 高 | P3 | 可能影响 Mid360 / D435 接入和后续建图。 | 阶段需要时再安装对应驱动，并优先使用成熟文档和可回退配置。 |
| FAST-LIO2 建图 / 定位效果不达预期 | 高 | P3 | P4 导航输入可能不稳定。 | 迭代一先追求基础地图和可观察定位，增强能力留到后续迭代。 |
| Nav2 配置和禁区约束调试延迟 | 高 | P4 | 可能影响自主导航闭环和高风险区域约束。 | 先单目标点，再多目标和异常场景；安全约束优先。 |
| 语义导航范围膨胀 | 中 | P5 | 可能挤压系统集成时间。 | 迭代一采用 YAML 语义位置表 + 规则匹配，复杂语义能力后置。 |
| 系统集成缓冲不足 | 高 | P6 | 可能影响最终验收、报告和演示素材。 | 每阶段结束后复盘并调整下一阶段范围，保留 P6 集成缓冲。 |

## 2. 当前边界

1. 风险登记不表示对应问题已经发生。
2. 风险关闭必须依赖真实测试、照片、日志、bag、视频或阶段复盘。
3. 风险登记不替代测试记录、BOM、接线图或实现文档。
4. 后续会随着 P2-P6 执行继续更新。
