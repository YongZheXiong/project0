# P2 H60 重建风险登记

> 状态：公开工程基线；风险关闭必须依赖到货、测量和测试证据。

| 风险 | 等级 | 当前缓解与关闭证据 |
| --- | --- | --- |
| H60/MC520 型号、针序或资料与目标不一致 | 高 | H0 核对丝印、接口、配件、R150、六芯线逐线通断和厂家资料 |
| AT8236 单路限流低于 MC520 堵转电流 | 高 | 低占空、单路到四路逐级测试，记录电流、压降和温升；不宣称具备完整堵转扭矩 |
| 急停释放后意外恢复运动 | 高 | H60 冷启动为 `DISARMED/PWM=0`，清旧命令/PID；Orin 锁存急停并要求新会话显式 ARM |
| Orin 保活、H60 失电时 UART 反供电 | 高 | H4 测量掉电侧电源轨和引脚；使用掉电高阻缓冲/隔离后方可固定连接 |
| 继电器、保险、线材或端子额定不匹配 | 高 | 以线材/端子和实测电流确定保护值；验证继电器 DC 分断能力和内置二极管方向 |
| 动力回生/浪涌损伤 H60 或电源 | 高 | 示波器观察制动、反转、急停和主开关断开瞬态，再决定吸收措施 |
| Mid360 支路在低电量或动力瞬态下掉电 | 高 | 验证升降压输入下限、冷启动峰值、压降、温升和点云连续性 |
| H60 VIN ADC 被误当作持续电池监控 | 中 | 多点校准；明确 H60 失电时无遥测，首版接受该可观测性缺口 |
| Orin 急停 GPIO/GND 或 pinmux 选择错误 | 高 | 断电核对载板针脚和 pinmux；外置上拉与串联限流；NO 只接 3.3V 干接点 |
| 新 CAD 加工公差、重心或维护空间不足 | 高 | 28 个 STEP 已通过数字 B-Rep 复审；加工件尚未交付，收货后检查材质/厚度/孔位/平面度并试装，再关闭质量/重心、动态离地、线束弯曲和维护空间 |
| 将旧平台测试结论迁移到新平台 | 高 | 旧 STM32/JGB/WSDC/CAD 文档标记历史；新平台从 H0 重新验收 |

任何高风险项未关闭时，不得将数字基线解释为可上电、可落地运动或可无人运行。
