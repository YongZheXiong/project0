# 迭代一 WBS 与 P2 重建计划

## 阶段总览

| 阶段 | 目标 | 最低退出条件 |
| --- | --- | --- |
| P2 | H60/MC520 底盘与基础运动成立 | H0-H8 通过，急停、超时停车和人工接管可复验 |
| P3 | 感知、建图与定位成立 | Mid360/D435 数据与基础地图、定位状态可观察 |
| P4 | 导航与避障成立 | 受控场景目标点导航和异常停车通过 |
| P5 | 语义导航与任务调度成立 | 确定性语义目标转换和任务结果闭环 |
| P6 | 系统集成与验收 | 全链路、安全专项、报告和演示证据完成 |

## P2 执行分解

| 工作包 | 内容 | 退出条件 |
| --- | --- | --- |
| P2-R1 到货与版本 | H60 V3.7、4 套 MC520P56、配套件和资料核对 | H0 通过 |
| P2-R2 新整车 CAD | 自主设计底盘，完成孔位、干涉、质量、重心、轮载和维护空间检查 | H1 通过 |
| P2-R3 断电电气 | 主/支路保护、继电器、NC/NO、极性、线束和端子检查 | H2 通过 |
| P2-R4 独立供电 | Orin、Mid360、H60 分支独立上电和电源质量测试 | H3 通过 |
| P2-R5 急停与反供电 | 急停切 H60、计算/感知保活、GPIO 反馈和 UART 掉电高阻 | H4 通过 |
| P2-R6 H60 安全固件 | DISARMED、显式 ARM、CRC/序号/会话、超时、IWDG 和异常撤 PWM | H5 通过 |
| P2-R7 悬空动力 | 单路到四路方向、编码器、斜坡、反转、限流、温升和浪涌 | H6-H7 通过 |
| P2-R8 落地低速 | 人工看守下的低速运动、停车距离、急停和链路故障测试 | H8 通过 |

P3-P6 保持阶段级滚动规划；新平台未完成 P2 验收前，不提前声明感知、导航或全系统能力已成立。
