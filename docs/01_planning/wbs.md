# 迭代一 WBS 与 Sprint 规划

> 文档状态：公开版 P2 执行规划基线
> 文件定位：本文用于公开说明 Project0 迭代一 P2-P6 的工作分解、阶段顺序和滚动规划口径。本文不包含内部 CR、私人过程记录或具体日历安排。

---

## 1. 规划口径

Project0 迭代一采用滚动规划：

1. P2 近期任务细化到可执行、可检查、可验收；
2. P3-P6 先保持阶段级规划；
3. 每完成一个阶段后，再基于真实调试结果细化下一阶段；
4. 具体日期和细化参数不在本文件中一次性冻结；
5. 仿真仅作为辅助工具，不替代真机验收。

---

## 2. 阶段总览

| 阶段 | 阶段目标 | 主要输出 | 最低退出条件 |
| --- | --- | --- | --- |
| P2 | 底盘与基础运动成立 | 可遥控运动小车、底层通信、急停和基础安全验证 | 小车可在人工监控下完成前进、后退、转向、停止；急停和通信中断停车可验证。 |
| P3 | 感知与定位建图成立 | 传感器数据发布、建图 / 定位链路、地图和数据记录 | 走廊基础地图可生成并复用，定位状态可观察。 |
| P4 | 导航与避障成立 | Nav2 配置、代价地图、禁区约束、目标点导航 | 小车可在真实走廊中完成目标点导航，遇到障碍或高风险区域能绕行或安全停车。 |
| P5 | 语义导航与任务调度成立 | 语义位置表、语义目标转换、基础任务状态机 | 已定义语义目标可转换为导航目标并反馈任务结果。 |
| P6 | 系统集成与迭代一验收 | 全链路联调、安全专项、验收记录、报告和演示素材 | 迭代一核心能力达到基础成立，系统可完整演示并留痕。 |

## 3. P2 Sprint 规划

| Sprint | 目标 | 主要工作 |
| --- | --- | --- |
| P2-S1 到货验收与装配前检查 | 确认 P2 是否具备安全装配条件 | 到货状态、机械孔位、固定件、线束工具和关键模块基础检查。 |
| P2-S2 机械装配与线束规划 | 建立不上电状态下的机械与线束基础 | 三层底盘、电机、板卡、传感器支架和线束路径初步整理。 |
| P2-S3 电源与急停安全验证 | 分支路验证电源和硬件急停边界 | 主电源、保险、急停、计算支路、控制支路和感知支路逐步验证。 |
| P2-S4 STM32 最小底层控制 | 确认 STM32 可下载、可控制、可安全停止 | 下载 / 调试路径、PWM、编码器、最小固件和低速电机验证。 |
| P2-S5 Orin NX 与 STM32 通信 | 建立上位机到底层控制板的最小闭环 | UART 最小收发、协议帧、状态上报和通信异常停车。 |
| P2-S6 遥控运动与阶段收束 | 完成可遥控运动小车和 P3 输入整理 | 手柄 / 键盘遥控、基础运动、急停验证、首段真机素材和阶段复盘。 |

## 4. P3-P6 阶段级规划

### P3：感知与定位建图

重点工作：

1. Mid360 接入与点云 / IMU 发布；
2. D435 RGB / 深度数据接入与记录；
3. TF 与传感器安装关系记录；
4. FAST-LIO2 建图与定位链路；
5. 地图保存、加载和建图数据记录。

### P4：导航与避障

重点工作：

1. Nav2 基础部署与配置；
2. 静态地图、障碍物层、膨胀层和高风险禁区配置；
3. 单目标点与多目标点导航；
4. 障碍物绕行、路径阻断和安全停车测试。

### P5：语义导航与任务调度

重点工作：

1. YAML 语义位置表；
2. 语义目标到导航目标的确定性转换；
3. 单任务生命周期管理；
4. 待机、手动、自主、急停等模式联动；
5. 语义导航端到端测试。

### P6：系统集成与验收

重点工作：

1. 系统启动与关闭流程；
2. 系统自检与运行准入；
3. 全链路联调；
4. 急停、人工接管、通信中断、定位异常和高风险区域安全专项；
5. 迭代一能力验收、报告和演示素材整理。

---

## 5. 当前边界

1. 本规划表示 P2 已正式启动，但不表示 P2 已完成。
2. 本规划不表示整车已经完成装配、急停闭环、UART、编码器、接线、上电或落地运动验证。
3. 仿真环境不作为 P2 前置条件；如硬件进度受阻，可作为并行辅助工作。
4. 后续阶段会按真实调试结果继续细化。
