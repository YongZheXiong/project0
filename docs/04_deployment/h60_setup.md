# OpenCTR H60 部署入口

> 文档状态：正式入口 / 实物部署尚未开始
> 适用版本：目标 OpenCTR H60 V3.7，最终以到货丝印和原理图版本确认
> 依据：当前 H60 + MC520 数字基线与公开验收门

## 当前已确认

1. H60 作为四路 MC520P56 电机/编码器的底层控制器。
2. 目标通信为 Orin NX UART；永久接线前必须关闭 H60 掉电反供电风险。
3. 板载 VIN ADC `PC0` 承接主电池电压监测；外置 Keyes 模块不装。
4. H60 J2/J3 不为 Orin 或 Mid360 供电。
5. H60 板载开关保持 ON；外置主开关管理整车电源。当前没有独立急停或继电器，主开关不得称为急停。

VIN ADC 只在 H60 上电时可用。H60 支路故障、维护断电或整车断电后，Orin 不再获得该电压遥测；它用于上电期间的母线电压观测，功能范围不含持续 SOC 监测。当前没有车载电流采样。

## 到货后部署顺序

1. H0：核对 V3.7 丝印、四个 R150、接口针序、板况、资料包和许可边界。
2. 建立不依赖不明 EXE/预编译 HEX 的可复现固件构建路径；记录工具版本、命令、产物散列和回滚件。
3. 不接电机，用限流电源验证输入、低压轨、板载开关、VIN ADC 和串口日志。
4. 实现并验证 `firmware/h60_motion_control_firmware_requirements_v0_2.md`。
5. 完成 UART 反供电保护后，再进行 Orin 双向通信和故障注入。
6. 按 H0-H8 计划逐级进入电机、动力和落地测试。

## 当前未完成

H60 尚未在本任务中确认采购、到货、连接、构建、烧录或运行。厂商示例和宣传功能不能自动关闭 Project0 的协议、看门狗、异常撤 PWM、ARM、热、回生或运动安全门。

公开产品入口：https://www.xtark.cn/product/show.php?itemid=7 。到货后仍以 V3.7 实物丝印、随附资料和电气测量为准。
