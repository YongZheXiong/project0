## 阅读说明

- “本次成果”只列可独立理解和复用的交付结果。
- “验证与证据”说明结论覆盖了什么。
- “已知限制”明确哪些能力仍不能由该版本推出。
- “使用或升级提示”给出读者复现或迁移时必须注意的事项。
- 开发流水和内部治理过程不进入公开发布说明。
