# Project0 v1.1-dev.2：H0 基线与 H60 安全控制检查点

> 类型：历史开发预发布
>
> 对应阶段：P2 / `v1.1`
>
> 发布日期：2026-09-01
>
> 状态：已发布并冻结

## 一句话说明

在 `v1.1-dev.1` 的重建基线上，冻结了 P2 的 H0 基线和一条可审计的 H60 安全控制检查链，但没有宣称 P2 或底盘运动验收完成。

## 本次成果

- H0 按发布时口径闭环，架构、接线、测试入口和证据关系能够追溯。
- H60 单控制器路径形成了以上电默认失能、显式使能、停车/失能、通信超时和故障撤 PWM 为核心的安全控制基线。
- 公开仓库的当前主线、历史边界和复现入口进一步统一。

## 验证与证据

- 发布前完成仓库结构、文档一致性、链接、敏感内容和相关离线测试检查。
- H60 结论只覆盖发布时已经执行和记录的单控制器安全控制检查。
- 标签内容保持冻结；后续现场结果不反向改变这个版本的验收边界。

## 已知限制

- 本版本不代表 H1-H8 全部门完成，也不代表四轮运动、手柄控制或自主能力已经验收。
- 已发布软件只覆盖当时的离线和受限安全基线，不能被当作完整动力运行版本。
- `-dev.N` 是历史命名；新阶段性成果版本使用 `vX.Y.N`，本标签不会重命名。

## 使用或升级提示

- 复核历史结果时应检出 `v1.1-dev.2` 标签，不能用当前 `main` 替代发布时内容。
- 任何动力测试都必须重新满足对应验收计划和现场安全条件。
