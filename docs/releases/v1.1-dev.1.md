- 发布前完成公开内容、相对链接、敏感信息和版本边界检查。
- 本版本的验证重点是重建基线与公开边界，不以底盘运动验收作为发布条件。
- 标签内容保持冻结；后续安全控制和现场试验属于后续版本或未发布进展。
