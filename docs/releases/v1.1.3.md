# Project0 v1.1.3：Nano 与 H60 架空控制基线

> 类型：P2 阶段性成果版本
>
> 发布日期：2026-11-14

## 一句话说明

冻结 Jetson Orin Nano 上的 ROS 2 模式与安全仲裁，以及真实手柄通过 Nano 和 H60 控制四轮时的架空运动、断连停车与恢复验证。

## 本次成果

- ROS 2 Humble 工作区提供六个包，包含系统模式、运动许可、指令仲裁、手柄输入和 H60 二进制协议桥。
- 架空试验覆盖前进、后退及左右方向、松开使能键停车、关闭无线手柄后的停车、重新建立会话，以及开机前已持使能键和前进输入时重连无自启。
- 公开六包源码、测试和可重建试验固件源码。默认固件及 ROS 2 启动配置保持运动锁定。

## 验证与证据

- Nano 实机完成六包构建、接口生成、五节点隔离启动与退出，以及 17 段 ROS 2 模式与仲裁场景。场景的手柄与底盘输入为软件替身。
- 架空试验另用真实手柄、Nano、H60 V3.7 与原 MC520P56 轮组。协议记录核对了运动指令、STOP 与重连后的使能状态，停轮由操作者观察。
- 公开候选树通过 72 项 ROS 2 源码侧检查和 H60 默认构建验证。使用 GNU Arm 14.3.1 重建的 28R2 固件与架空实测的 12,012 字节制品逐字节一致。详见[验证报告](../../reports/nano_h60_raised_control_v1_1_3.md)。

## 已知限制

- P2 工程暂停，阶段验收仍待。架空试验尚未提供地面停车距离、完整落地运动、生产里程计或长时热负荷证据。
- 原轮组的落地短直行已观察到，轻左弧仍近直。新支架及霍尔电机的实际装配和带载效果待验证。
- D435 与 Mid360 已分别取得有界数据证据。深度精度、传感器最终装车及导航集成仍待验证。

## 使用或升级提示

按[ROS 2 源码说明](../../src/README.md)运行本地测试与无运动启动，按[固件源码说明](../../firmware/h60_safe_control/README.md)复编并检查默认运动锁。28R2 是当时架空试验配置，发布包以源码供审阅和复现，设备部署仍依据实际硬件与验收条件。
