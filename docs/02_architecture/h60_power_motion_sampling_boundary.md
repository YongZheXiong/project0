# H60 当前电源、运动约束与采样边界

> 状态：公开数字基线 / 尚未形成实物、上电或运动准入
> 更新：2026-08-20

## 当前电源树

```text
3S 主电池
-> 25A 主输入保险
-> 外置主电源开关
-> 带支路保护的分配节点
   +-> H60 支路 -> H60 J1 -> 4 × MC520P56
   +-> Orin 支路 -> 12V DC-DC -> Orin NX
   +-> Mid360 支路 -> 12V DC-DC -> Mid360
```

H60、Orin 和 Mid360 的支路保险值必须结合线径、端子、稳态电流、峰值电流和温升证据冻结，不能沿用上一平台路号或凭经验直接放大。

## 当前不存在的硬件

当前 H60 新车不安装：

- 独立蘑菇急停按钮；
- 急停继电器或接触器；
- 继电器线圈支路；
- 急停状态 GPIO；
- Keyes 外置电压模块；
- ACS712 或其他车载电流采样模块。

上一 STM32 小车中的对应器件、接线和测试保存在历史资料中。主开关用于人工断开整车电源；当前车辆没有独立急停装置。

## 停车、失能与恢复

1. H60 上电、复位、棕断恢复和看门狗复位后保持 `DISARMED / PWM=0`。
2. 只有自检、链路、故障状态、命令新鲜度和输入回中满足要求后，新会话显式 ARM 才能使能运动。
3. STOP、DISARM、通信超时、非法帧、序号回退、IWDG 和固件异常入口必须先撤销四路 PWM。
4. 速度、加速度、反转和首次占空比采用保守限值；换向必须经过零输出。
5. H60、Orin 或 UART 链路重启后不得自动恢复运动。
6. 首次动力测试必须架空、低能量、轮周净空并由操作者持续监看；落地低速必须在 H0-H7 全部通过后另行授权。

当前没有独立硬件急停，因此测试区域、速度、监护、主开关可达性和逐门准入必须更保守。楼梯口、边缘区域、电梯口和排水槽附近不得作为早期运动测试区。

## UART 单侧掉电

H60 或 Orin 的支路故障、维护断电和启动时序都可能形成单侧上电。永久连接前必须分别验证两侧掉电组合，测量对侧电源轨、UART 引脚和反灌电流；必要时采用掉电高阻缓冲或数字隔离。反供电门未关闭前，不制作永久运动线束。

## 采样边界

- 当前车载采样只有 H60 `PC0` VIN ADC；完成多点校准后才能用于状态上报。
- VIN 只代表 H60 支路上电期间的电压，不是独立电池监测，也不能在 H60 失电时持续观测。
- 当前没有车载电流遥测。外部仪表在台架中得到的电流只作为测试证据。
- H60 驱动内部限流或过流保护不能被描述为可记录的电流采样功能。
