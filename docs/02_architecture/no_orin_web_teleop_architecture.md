# 无 Orin 本机网页控制覆盖层

## 定位

当最终上位机暂不可用时，Project0 使用一个临时、可撤销的本机覆盖层验证 H60 控制链，不改变最终的 ROS2 + H60 架构：

```text
浏览器 -> localhost 后端 -> H60 链路适配器 -> H60
```

浏览器只表达 STOP、DISARM、ARM 请求和受限方向意图；后端负责身份门、短租约、旧请求拒绝、断连停车、日志和故障锁止；H60 继续负责默认失能、显式 ARM、75 ms 非零命令租约、IWDG 与故障撤输出。

## 分层

| 层 | 职责 |
| --- | --- |
| 网页 | 只发受限意图，不生成 PWM、串口帧或生产轮速 |
| localhost 后端 | 独占会话、客户端序号、租约、超时与审计 |
| H60 链路 | 把已批准的高层意图映射为受限协议命令 |
| H60 固件 | 最终 ARM、命令新鲜度、故障和输出安全门 |

## Fail-closed 行为

- 未 ARM、身份漂移、遥测超时或协议错误时拒绝运动；
- 浏览器断开或命令租约过期时发送 STOP/DISARM；
- 方向改变不能直接穿越零点，必须先 STOP 并重新 ARM；
- STOP 未确认、日志写入失败或链路状态未知时锁定故障；
- 恢复连接后不恢复旧命令，旧客户端请求保持失效。

## 公开实现边界

`tools/no_orin_web_teleop/` 公开的是 fake serial 演示、状态机、网页和自动测试。真实设备身份、一次性现场流程和运行授权不进入公开仓库。

## 验证边界

H60-only 架空四轮前进、后退、STOP 与定性断链停车已经形成受限证据，但不覆盖上位机、落地、负载、热、长时、精确停轮时序或完整 H7/H8。
