# P2 底盘、主机与连接基线

## 当前已验证配置

[v1.1.3](../releases/v1.1.3.md) 冻结 Jetson Orin Nano 8GB、OpenCTR H60 V3.7 与原四台 MC520P56 电机的架空验证。Nano 接收无线手柄输入，经 USB-COM 与 H60 交换带会话和状态字段的二进制消息。原 Orin NX/C1902 以及 H60-only 配置的资料对应各自历史验证条件。

| 部件 | 职责与接口 |
| --- | --- |
| Orin Nano 8GB | ROS 2 上位机、手柄接收、系统模式和安全仲裁。 |
| H60 V3.7 | 四路电机和编码器、低层失能及超时停车、VIN 观察。 |
| 传感器 | D435 经 USB，Mid360 经以太网。两者分别有有界数据证据，整车集成和导航仍待。 |
| 供电 | 3S 电池经总保险和外置主开关后分至 H60、Nano 与 Mid360 的受保护支路。 |

USB-COM 已用于架空实测。单侧掉电及反向供电的电气影响仍有未覆盖工况。H60 只有 VIN 采样，当前无逐路电流遥测。软件停止、默认失能、显式使能、超时、看门狗与主电源的作用边界见[验收计划](../06_testing/p2_h60_mc520_rebuild_acceptance_plan_2026-08-16.md)。

## 当前工程停点

底盘工程暂停在 P2。原 MC520P56 轮组的短直行已有观察记录，轻左弧未形成预期航向变化。新支架及霍尔编码器电机待验证实际装配、轮载和带载效果。生产参数、轮式里程计和完整落地验收仍待。
