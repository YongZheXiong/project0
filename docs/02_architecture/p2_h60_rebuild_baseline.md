# P2 H60 + MC520 当前实现基线

> 文档状态：正式 / 当前实现覆盖层
> 技术边界：见 `h60_power_motion_sampling_boundary.md`
> 适用范围：P2 重建、采购确认、CAD、接线、固件和验收
> 状态边界：数字基线已批准；未确认采购、到货、接线、上电或运动

## 1. 当前与历史边界

H60 新车采用 OpenCTR H60 V3.7、四套 MC520P56、Orin NX、Mid360 和 D435。旧文档中的 STM32、WSDC2412D、JGB37-520、Keyes、ACS712、急停/继电器、CTRL-001、六路保险盒和三层底盘属于上一实车基线；其历史记录仍有效，但不定义当前重建方案。

## 2. 当前拓扑

```text
3S battery -> 25A main fuse -> main switch -> fused distribution
                                              +-> H60 branch -> H60 -> 4 x MC520P56
                                              +-> Orin DC/DC -> Orin NX -> D435 / gamepad
                                              +-> Mid360 DC/DC -> Mid360

Orin NX <---------------- versioned, protected UART ----------------> H60
Mid360 <-------------------------- 100BASE-TX ----------------------> Orin NX
D435 <------------------------------ USB 3 -------------------------> Orin NX
```

当前没有独立急停按钮、急停继电器、急停 GPIO 或车载电流采样。主开关用于整车断电，不得称为急停。

## 3. 职责划分

| 实体 | 当前职责 | 明确不承担 |
| --- | --- | --- |
| Orin NX | ROS2、感知、定位、导航、任务、手动/自动仲裁、显式 ARM、日志 | 电机实时 PWM；在链路丢失后替 H60 本地停车 |
| H60 | 四路编码器、四路驱动、速度闭环、命令超时、IWDG、故障撤 PWM、VIN ADC | Orin/Mid360 供电；车载电流遥测 |
| COMP-001 | Orin 独立 12V 供电 | Mid360/H60 供电 |
| SENS-009 | Mid360 独立 12V 供电 | Orin/H60 供电 |
| 主开关 | 人工断开整车电源 | 独立急停或认证安全功能 |

## 4. 旧实现映射

| 旧实现 | 当前实现 | 处理方式 |
| --- | --- | --- |
| STM32F407 控制板 | OpenCTR H60 V3.7 | 旧部署/固件/测试只读保留；新固件单独实现 |
| 2 × WSDC2412D | H60 4 × AT8236 集成驱动 | 旧接线、温升和额定结论不可迁移 |
| 4 × JGB37-520 + 83–85 mm 轮 | 4 × MC520P56 + 65 mm 轮 | 旧 CPR、轮径、速度和载荷不可迁移 |
| Keyes 外置电压采样 | H60 `PC0` VIN ADC | 多点校准后生效 |
| ACS712 总电流采样 | 不安装 | 当前没有车载电流采样；外部仪表只作调试 |
| 急停按钮/继电器/NO 反馈 | 不安装 | 历史记录保留；当前运动约束见 `h60_power_motion_sampling_boundary.md` |
| CTRL-001 5V 支路 | 不纳入当前 | H60 内部低压供电，其他负载独立支路 |
| 三层冻结 CAD | 用户新两层 CAD | 旧 CAD 只作历史参考 |

## 5. 运动状态机与处置

| 事件 | H60 要求 | Orin 要求 | 人工边界 |
| --- | --- | --- | --- |
| 上电/复位 | `BOOT -> DISARMED`，PWM=0，清旧状态 | 启动并保持未授权 | 先完成静止检查 |
| 新的人工 ARM | 自检、心跳、故障和命令新鲜度通过才使能 | 新会话、输入回中、新鲜命令 | 明确进入测试门 |
| UART 超时/Orin 故障 | 本地超时撤 PWM、清控制状态 | 停止发布并记录故障 | 必要时关闭主开关 |
| H60 看门狗/异常 | 异常入口先撤 PWM，再复位或保持故障 | 识别链路丢失并锁止运动 | 回到不上电检查 |
| 主开关断开 | 整车失电 | 不适用 | 仅作人工断电，不称急停 |

## 6. 采样

- 车载采样：H60 `PC0` VIN ADC 电压，多点校准后上报。
- 不具备：车载电流采样、H60 失电后的持续电池观测、长期 SOC 估计。
- H60 驱动内部电流调节/过流动作不等同于电流遥测。

## 7. 当前阻断项

1. 实物、版本、线材、端子和支路保护尚未现场冻结。
2. UART 任一侧掉电反供电尚未关闭。
3. H60 的 ARM、超时、IWDG、异常撤 PWM 与协议恢复尚未实现。
4. 单路/四路持续能力、温升、回生和主开关断开瞬态尚未测试。
5. VIN ADC 尚未完成多点校准。
6. 新 CAD 尚未完成实物试装、质量/重心、维护空间和线束路径验证。
7. Mid360 支路的低电量、冷启动峰值和动力瞬态稳定性尚未验证。
8. 当前无独立硬件急停，落地运动必须使用更严格的低能量、人工监看和场地隔离条件，并由用户单独授权。

任一阻断项未关闭时，不得把数字基线解释为可上电、可落地运动或可无人运行。
