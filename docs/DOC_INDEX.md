# DOC_INDEX.md

## 1. 文件作用

本文档是项目0的文档索引与依赖关系说明文件。

它用于说明：
1. 项目0有哪些主要文档；
2. 每类文档负责什么；
3. 哪些文档是上游定义；
4. 哪些文档是下游承接；
5. 修改某类内容时应同步检查哪些文件。

本文档不替代任何正式设计文档，只负责说明文档之间的关系。

---

## 2. 文档体系总览

项目0文档体系当前主要包括：

1. `docs/00_definition/`：项目定义文件集；
2. `docs/01_planning/`：P1 功能落地、技术选型、WBS、采购清单；

4. `process/decisions/`：关键决策记录；
5. `CHANGELOG.md`：版本变更记录；
