# STM32 悬空同侧联动与四轮联动短脉冲测试记录 v0.1

## 1. 文件作用

本文档记录 Project0 P2 阶段在四个单电机低占空比短脉冲测试通过后，继续进行的悬空同侧双电机联动、四轮联动、方向一致性和相关诊断过程。

本文档不是正式底盘控制固件设计，不包含编码器读取、闭环调速、UART 通信、ADC 采样、ROS2 通信、急停闭环或整车落地运动控制。

## 2. 工程位置

本记录对应的 STM32CubeIDE 测试工程保存在本地开发环境中。该工程在本轮测试中被多次临时修改用于诊断和联动测试。测试结束后，工程最终已恢复并烧录回安全初始化行为：`PWM=0`，`INA=H`，`INB=H`。

## 3. 测试目标

本阶段临时测试回答以下问题：

1. 左侧 `LF + LR` 能否在悬空条件下短时同向起转；
2. 右侧 `RF + RR` 能否在悬空条件下短时同向起转；
3. 四个轮子能否在悬空条件下同时短时起转；
4. 在当前测试定义的“从车尾向车头看，朝车头方向为正方向”口径下，四轮方向能否通过软件补偿保持一致。

它不回答以下问题：

1. 编码器信号和符号是否正确；
2. 整车落地后是否能直行、转向或稳定停车；
3. 急停链路是否已切断动力；
4. 正式底盘控制固件是否完成。

## 4. 测试前提

| 项目 | 本次状态 |
|---|---|
| 测试策略 | 轮子悬空、人工看守、短时脉冲、先分侧再四轮 |
| 安全默认 | `PWM=0, INA=H, INB=H`，电驱脱机 |
| 临时触发方式 | STM32 实体 `RESET` 后延时约 `5s`，按固定顺序执行 |
| 初始联动参数 | `TIM4` 比较值 `8`，约 `14%` 到 `15%` 占空比，约 `500ms` |
| 诊断后联动参数 | `TIM4` 比较值 `20`，约 `36%` 占空比，约 `200ms` |
| 联动阶段间隔 | 约 `8s` |
| 急停机械安装 | 未完成 |
| 收尾要求 | 测试结束后烧回安全初始化固件 |

## 5. 当前实测控制映射与方向口径

### 5.1 通道映射

| 电机 | 实际电驱 / 通道 | STM32 PWM | STM32 INA | STM32 INB | TIM4 通道 |
|---|---|---|---|---|---|
| `LF` 左前 | DRV-L `M1 / CH1` | `PB6` | `PD0` | `PD1` | `TIM4_CH1` |
| `LR` 左后 | DRV-L `M2 / CH2` | `PB7` | `PD2` | `PD3` | `TIM4_CH2` |
| `RF` 右前 | DRV-R `M2 / CH2` | `PB9` | `PD6` | `PD7` | `TIM4_CH4` |
| `RR` 右后 | DRV-R `M1 / CH1` | `PB8` | `PD4` | `PD5` | `TIM4_CH3` |

### 5.2 方向定义

当前测试采用的方向定义为：

```text
从车尾向车头看，朝车头方向为正方向 / 向前。
```

按该定义，实测结果为：

1. 左侧在 `INA=L, INB=H` 时朝正方向；
2. 右侧在 `INA=L, INB=H` 时朝反方向；
3. 因此悬空联动测试固件对右侧采用软件反向补偿：`INA=H, INB=L`。

## 6. 初始联动测试与问题现象

在四个单电机测试通过后，曾先尝试把同侧联动和四轮联动直接建立在单电机阶段的保守参数之上：

| 参数 | 初值 |
|---|---|
| 比较值 | `8` |
| 占空比 | 约 `14%` 到 `15%` |
| 持续时间 | 约 `500ms` |

首次联动现象：

1. `LF` 在左侧联动阶段不转；
2. `LR` 可转；
3. 右侧两个轮子均可转，但方向与左侧相反；
4. 当时不能直接下结论说 `LF` 硬件损坏，因为其单电机测试此前通过。

## 7. LF 链路诊断过程

针对 `LF` 在联动时不转，依次执行了以下诊断：

### 7.1 动力链路复核

1. 左电驱 `P+ / P-` 供电复核通过；
2. 左侧支路保险导通正常；
3. `LF` 动力线、`DRV-L M1A / M1B` 通断检查正常；
4. 后续还发现保险盒正极输入端螺丝有松动并重新紧固，说明配电点仍需后续防松复查。

### 7.2 PWM 控制线诊断

仅保留 STM32 / 控制端上电，不接主动力，现场测得：

```text
DRV-L PWM1 在诊断窗口内约 3.26V
```

说明 `PB6 -> DRV-L PWM1` 控制线正常。

### 7.3 方向线诊断

仅保留 STM32 / 控制端上电，不接主动力，方向诊断固件保持：

```text
PWM = 0
LF_INA = L
LF_INB = H
```

现场确认：

1. `INA1` 低电平正常；
2. `INB1` 高电平正常。

说明 `PD0 / PD1 -> DRV-L INA1 / INB1` 方向线正常。

### 7.4 GPIO 直拉高绕过诊断

在接主动力、轮子悬空前提下，临时用 `PB6` 作为普通 GPIO 直拉高，绕过 `TIM4_CH1` 输出一个极短脉冲，`LF` 能动。

这一步说明：

1. `LF` 电机本体、左电驱 `M1` 功率通道和动力线可工作；
2. 不能简单写成 `LF` 硬件损坏。

### 7.5 TIM4_CH1 高占空比诊断

继续保持 `TIM4_CH1` 正常 PWM 路径，只把占空比提高到接近 `100%`，输出极短脉冲后，`LF` 同样能动。

阶段结论：

```text
LF 问题不是硬件损坏，也不是 TIM4_CH1 通道失效。
更符合“联动场景下，原 compare=8 的低占空比起转门槛不足”。
```

## 8. 最终联动测试固件行为

在完成上述诊断后，联动测试固件最终采用以下行为：

```c
safe_offline_state();
HAL_Delay(5000);

left_pair:   INA=L, INB=H, compare=20, pulse=200ms
HAL_Delay(8000);

right_pair:  INA=H, INB=L, compare=20, pulse=200ms
HAL_Delay(8000);

all_wheels:  left side INA=L/INB=H, right side INA=H/INB=L,
             compare=20, pulse=200ms

safe_offline_state();
```

说明：

1. `compare=20` 对 `Period=55` 约为 `36%` 占空比；
2. 右侧采用软件反向补偿，仅作为当前测试固件方向表；
3. 每轮测试完成后，固件仍回到 `PWM=0, INA=H, INB=H`。

## 9. 最终测试结果

### 9.1 同侧联动

| 阶段 | 结果 | 方向 |
|---|---|---|
| 左侧 `LF + LR` | 通过 | 均朝正方向 |
| 右侧 `RF + RR` | 通过 | 在软件反向补偿后均朝正方向 |

### 9.2 四轮联动

| 阶段 | 结果 | 方向 |
|---|---|---|
| `LF + LR + RF + RR` 同时短脉冲 | 通过 | 四轮均朝正方向 |

阶段结论：

```text
悬空条件下，同侧双电机联动和四轮联动均已通过。
按当前方向定义，右侧需要软件反向补偿后与左侧保持一致。
测试结束后，STM32 已烧回安全初始化固件。
```

## 10. 边界和后续要求

已完成：

1. 四个单电机短脉冲测试；
2. `LF` 低占空比起转门槛问题定位；
3. 悬空同侧双电机联动；
4. 悬空四轮联动；
5. 悬空方向一致性验证；
6. 测试后安全初始化回烧。

未完成：

1. 编码器接线和读取；
2. 线束最终固定、防松、防振、防拉扯整理；
3. 急停机械安装和急停继电器切断链路验证；
4. 整车落地低速运动；
5. 正式底盘控制固件。

后续要求：

1. 正式底盘控制固件必须显式记录当前方向表，不能默认左右同向参数完全相同；
2. 后续起步限幅和最低有效占空比应考虑 `LF` 的联动起转门槛，不能直接沿用 `compare=8`；
3. 未完成急停闭环前，不进入无人看守或整车落地动力测试；
4. 每轮动力测试结束后仍应烧回安全初始化或确认正式固件默认安全态。
