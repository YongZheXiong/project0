# STM32 左前单电机短脉冲测试固件记录 v0.1

## 1. 文件作用

本文档记录 Project0 P2 阶段左前 `LF` 单电机低占空比短脉冲测试所用的临时 STM32 固件行为、硬件接线、诊断过程和测试结果。

本文档不是正式底盘控制固件设计，不包含闭环控制、编码器读取、UART 通信、ADC 采样、ROS2 通信或四电机运动控制。

## 2. 工程位置

本记录对应的 STM32CubeIDE 测试工程保存在本地开发环境中。该工程当前仍未纳入公开仓库源码管理，公开仓库只记录测试事实、关键配置和安全边界。

## 3. 测试目标

本次临时测试只回答一个问题：

```text
在受控条件下，STM32 能否通过 DRV-L 的 M1 通道让左前 LF 电机短时转动。
```

它不回答以下问题：

1. 四个电机方向是否一致；
2. 左后、右前、右后电机是否可转；
3. 编码器是否能读取；
4. 整车落地后是否能直行；
5. 急停链路是否已经有效；
6. 正式底盘控制固件是否完成。

## 6. 诊断过程

本次测试前曾出现 DRV-L `PWM1` 测点始终约 `0V` 的现象。后续按从简单到复杂的顺序排查：

1. 先把 `PB6` 临时配置为普通 GPIO 输出高电平，保持约 `10s`；
2. 现场确认 STM32 `PB6` 引脚侧电压正常；
3. 现场确认 DRV-L `PWM1` 端子侧电压正常；
4. 再把 `PB6` 配置回 `TIM4_CH1` PWM 输出；
5. 使用约 50% 占空比 PWM 诊断，现场确认 DRV-L `PWM1` 端子侧有正常输出；
6. 最后进入左前电机短脉冲测试。

结论：

```text
PB6 引脚、PB6 到 DRV-L PWM1 的控制线、TIM4_CH1 PWM 输出路径均已通过阶段诊断。
```

## 7. 临时测试固件行为

临时测试固件采用 `TIM4_CH1` 输出 `PB6` PWM。

关键行为：

1. 上电后先保持安全状态；
2. 延时约 `5s`，给现场操作者留出观察和断电准备时间；
3. 设置左前方向为 `INA=L, INB=H`；
4. 将 `TIM4_CH1` 比较值设为 `8`；
5. 当前 `TIM4` 周期参数下，对应约 `14%` 到 `15%` 占空比；
6. 保持约 `500ms`；
7. 将 PWM 重新设为 `0`；
8. 将方向恢复为 `INA=H, INB=H` 脱机；
9. 程序留在安全空循环中。

伪代码描述：

```c
safe_offline_state();
HAL_Delay(5000);

HAL_GPIO_WritePin(LF_INA_GPIO_Port, LF_INA_Pin, GPIO_PIN_RESET);
HAL_GPIO_WritePin(LF_INB_GPIO_Port, LF_INB_Pin, GPIO_PIN_SET);

HAL_TIM_PWM_Start(&htim4, TIM_CHANNEL_1);
__HAL_TIM_SET_COMPARE(&htim4, TIM_CHANNEL_1, 8);
HAL_Delay(500);

__HAL_TIM_SET_COMPARE(&htim4, TIM_CHANNEL_1, 0);
safe_offline_state();
```

## 9. 边界和后续要求

1. 本次只验证左前 `LF` 一条链路；
2. 左后 `LR`、右前 `RF`、右后 `RR` 未做动力测试；
3. 本次不冻结电机正反方向定义；
4. 编码器未读取；
5. 整车未落地运动；
6. 急停机械安装与急停链路仍未完成；
7. 临时测试固件不是常驻安全固件；
8. 本轮测试结束后，STM32 必须烧回安全初始化状态。
