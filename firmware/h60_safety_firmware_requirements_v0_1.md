# H60 安全固件要求 v0.1

> 状态：正式需求，尚未实现。

## 状态机

最小状态为 `BOOT -> DISARMED -> ARMED -> FAULT/ESTOP_LATCHED`。

1. 上电、复位、棕断恢复和看门狗复位后必须进入 `DISARMED`，四路 PWM 为 0。
2. 清除上一会话速度目标、PID 状态、方向切换状态和命令序号。
3. 自检、心跳和本地故障检查通过后，只接受新会话的显式 ARM。
4. ARM 前速度目标必须为零，操纵输入需回中；缓存命令或保持的摇杆不得通过。
5. STOP、超时、非法帧、序号回退、异常和本地故障必须先撤四路 PWM。
6. 急停后重新上电不得记忆 ARMED。

## 协议与控制

协议至少包含版本、长度、会话 ID、单调序号、CRC、ARM/DISARM/STOP、速度命令、心跳、四轮计数/速度、故障、VIN、固件版本和状态机状态。对未知命令、过长帧、CRC 错误和过期序号采用失效导向处理。

速度闭环应有输出限幅、加减速斜坡、积分抗饱和和反转零速保持。没有电流遥测时不得宣称实现软件堵转保护。PC0 VIN ADC 必须多点校准，其监测不能替代 BMS 和保险。

## 异常与验收

启用 IWDG；HardFault 等异常入口先撤 PWM。要求可复现构建，上电/复位重复测试无非零 PWM，急停复位不自动运动，UART 断开/停发/乱码/Orin 重启自动停车，看门狗与故障注入先撤 PWM。电源、急停、反供电、温升和机械门通过后才允许落地测试。
