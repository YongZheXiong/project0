# STM32 四电机单电机短脉冲测试固件记录 v0.1

## 1. 文件作用

本文档记录 Project0 P2 阶段 `LF / LR / RF / RR` 四个电机分别进行单电机低占空比短脉冲测试时的临时 STM32 固件行为、控制映射、诊断过程、主输入保险故障处理和最终测试结果。

本文档不是正式底盘控制固件设计，不包含闭环控制、编码器读取、UART 通信、ADC 采样、ROS2 通信、四轮联动控制或方向一致性定义。

## 2. 工程位置

本记录对应的 STM32CubeIDE 测试工程保存在本地开发环境中。该工程当前仍未纳入公开仓库源码管理，公开仓库只记录测试事实、关键配置和安全边界。

## 3. 测试目标

本阶段临时测试只回答一个问题：

```text
在受控条件下，STM32 能否分别通过两块电驱的四个通道让四个电机单独短时转动。
```

它不回答以下问题：

1. 四个电机正向是否一致；
2. 左右轮编码器符号是否一致；
3. 同侧双电机是否能同步；
4. 四轮是否能联动；
5. 整车落地后是否能直行或转向；
6. 急停链路是否已经有效；
7. 正式底盘控制固件是否完成。

## 4. 测试前提

| 项目 | 本次状态 |
|---|---|
| 测试策略 | 低占空比、短时间、一次只测一个电机 |
| 轮子状态 | 全部悬空 |
| 人工看守 | 有 |
| 安全默认 | `PWM=0, INA=H, INB=H`，电驱脱机 |
| 临时触发方式 | STM32 实体 `RESET` 后延时约 `5s`，只执行一次脉冲 |
| 脉冲参数 | `TIM4` 比较值 `8`，约 `14%` 到 `15%` 占空比，约 `500ms` |
| 急停机械安装 | 未完成 |
| 收尾要求 | 每轮临时测试后烧回安全初始化固件 |

## 5. 当前实测控制映射

左侧保持早期规划映射；右侧按最终实物走线便利性采用与早期规划相反的电驱通道映射。

| 电机 | 实际电驱 / 通道 | STM32 PWM | STM32 INA | STM32 INB | TIM4 通道 | 电机动力线 |
|---|---|---|---|---|---|---|
| `LF` 左前 | DRV-L `M1 / CH1` | `PB6` | `PD0` | `PD1` | `TIM4_CH1` | 红线 -> `M1A`，白线 -> `M1B` |
| `LR` 左后 | DRV-L `M2 / CH2` | `PB7` | `PD2` | `PD3` | `TIM4_CH2` | 红线 -> `M2A`，白线 -> `M2B` |
| `RF` 右前 | DRV-R `M2 / CH2` | `PB9` | `PD6` | `PD7` | `TIM4_CH4` | 红线 -> `M2A`，白线 -> `M2B` |
| `RR` 右后 | DRV-R `M1 / CH1` | `PB8` | `PD4` | `PD5` | `TIM4_CH3` | 红线 -> `M1A`，白线 -> `M1B` |

注意：

```text
右侧当前有效映射与早期文档假设不同：
早期假设：RF=M1，RR=M2
当前实物：RF=M2，RR=M1
```

后续正式底盘控制固件必须按当前实物映射实现，或在改线后同步更新本记录。

## 6. 临时测试固件通用行为

每次单电机测试只打开目标通道，其余通道保持 `PWM=0, INA=H, INB=H`。

通用伪代码：

```c
safe_offline_state();
HAL_Delay(5000);

target_INA = GPIO_PIN_RESET;
target_INB = GPIO_PIN_SET;

HAL_TIM_PWM_Start(&htim4, target_channel);
__HAL_TIM_SET_COMPARE(&htim4, target_channel, 8);
HAL_Delay(500);

__HAL_TIM_SET_COMPARE(&htim4, target_channel, 0);
safe_offline_state();
```

测试结束后，STM32 已烧回安全初始化固件。

## 7. 诊断过程摘要

### 7.1 左前 LF

`LF` 详见 `firmware/stm32_lf_single_motor_pulse_test_v0_1.md`。关键诊断为：

1. `PB6` 普通 GPIO 高电平 10s 诊断通过；
2. `TIM4_CH1 / PB6` PWM 诊断通过；
3. `LF / DRV-L / M1` 短脉冲转动通过。

### 7.2 左后 LR

`LR` 初次采用更保守参数 `compare=5`、约 `300ms` 未转动。后续执行：

1. 使用 `PB7` 普通 GPIO 高电平 10s 诊断，DRV-L `PWM2` 能稳定测得约 `3.3V`；
2. 恢复 `TIM4_CH2 / PB7`，采用 `compare=8`、约 `500ms`；
3. `LR / DRV-L / M2` 短脉冲转动通过。

### 7.3 右前 RF

`RF` 初次按早期假设使用 `DRV-R M1 / PB8 / PD4 / PD5` 测试未转动。后续发现实物接线为：

```text
RF 红线 -> DRV-R M2A
RF 白线 -> DRV-R M2B
```

因此将软件测试目标改为 `DRV-R M2 / PB9 / PD6 / PD7`。测试结果：

1. `PB8 -> DRV-R PWM1` 诊断曾通过，用于确认早期 M1 控制线；
2. 改按实际接线 `PB9 / PD6 / PD7` 后，`RF / DRV-R / M2` 短脉冲转动通过。

### 7.4 右后 RR

`RR` 实物接线为：

```text
RR 红线 -> DRV-R M1A
RR 白线 -> DRV-R M1B
```

测试过程：

1. 断电检查 DRV-R `M1A / M1B` 到 RR 电机线导通，现场确认正常；
2. 方向诊断固件保持 PWM=0，仅将 `PD4 / INA1` 拉低、`PD5 / INB1` 保持高电平；
3. 现场测得 `INA1` 低电平约 `0.18V`，可视为有效低电平，`INB1` 约 `3.3V`；
4. 恢复 `TIM4_CH3 / PB8` 短脉冲测试后，`RR / DRV-R / M1` 转动通过。

## 8. 主输入保险故障与处理

在 `LR` 测试准备过程中，现场听到疑似打火 / 噼啪声，随后发现左电驱动力上电异常。后续排查结果：

1. 电源开关输入端端子在移动第三层底板时松脱；
2. 主输入 25A ATO / ATC 保险丝熔断，保险丝本体测得 `OL`，内部熔断结构已断开；
3. 该现象与端子松动导致间歇接触、打火、瞬时过流高度吻合；
4. 现场更换电源开关输入端端子；
5. 现场更换同规格 25A ATO / ATC 主输入保险丝；
6. 断电通断检查、短时上电观察和左 / 右电驱动力输入检查恢复正常。

处理边界：

1. 不允许用导线短接保险丝；
2. 不允许为避免熔断而擅自换更大规格保险丝；
3. 该故障说明线束防拉扯、端子压接和层间移动余量仍需后续复查；
4. 该故障不改变 DEC-026 的主输入保险选型结论。

## 9. 测试结果

| 电机 | 实际通道 | 结果 | 备注 |
|---|---|---|---|
| `LF` | DRV-L `M1 / CH1` | 通过 | 已在左前单电机测试记录中先行记录 |
| `LR` | DRV-L `M2 / CH2` | 通过 | 经 `PB7 / PWM2` 诊断后通过 |
| `RF` | DRV-R `M2 / CH2` | 通过 | 右侧按实物映射调整后通过 |
| `RR` | DRV-R `M1 / CH1` | 通过 | 经 M1 方向诊断后通过 |

阶段结论：

```text
四个电机均已完成单电机低占空比短脉冲动力测试。
每次测试均要求轮子悬空、人工看守、短时低占空比、一次只测一个电机。
测试后 STM32 已烧回安全初始化固件。
```

## 10. 边界和后续要求

已完成：

1. 电驱控制端安全初始化验证；
2. `LF / LR / RF / RR` 四个单电机短脉冲动力测试；
3. 右侧最终实物映射确认；
4. 主输入保险熔断故障定位与初步修复。

未完成：

1. 四轮方向一致性验证；
2. 编码器接线和读取；
3. 同侧双电机联动；
4. 四轮联动；
5. 整车落地低速运动；
6. 急停机械安装和继电器切断链路验证；
7. 线束最终固定、防拉扯、防振动整理；
8. 正式底盘控制固件。

后续要求：

1. 后续固件必须按当前实物映射处理右侧 `RF / RR`；
2. 正反转切换前仍必须先将 PWM 降为 `0%`；
3. 未完成急停链路前，不进行无人看守或落地动力测试；
4. 每次动力测试结束后仍应烧回安全初始化或确认正式固件默认安全态；
5. 在进入同侧双电机或四轮测试前，应先记录四个电机的实际转向。
