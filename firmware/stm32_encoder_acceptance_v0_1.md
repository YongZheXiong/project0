# STM32 新映射编码器低功率验收记录

## 1. 测试目标

本记录用于公开说明 P2 阶段 STM32 新映射固件下的 UART 和四路编码器基础验收结果。

本轮只验证：

1. STM32 可通过 USART3 周期输出状态文本；
2. Orin NX 可读取 STM32 输出；
3. 四路编码器 A/B 相接入和定时器计数在低功率手动转轮条件下成立；
4. 左前 `LF` 编码器异常的故障定位与替换后复验结果。

本轮不验证：

1. 主动动力控制；
2. 正式底盘控制协议；
3. 通信中断停车；
4. 无新指令停车；
5. 编码器方向符号归一化；
6. 里程计；
7. 悬空动力或落地低速运动。

## 2. 公开引脚摘要

### 2.1 编码器输入

| 电机 | STM32 引脚 | 定时器 |
| --- | --- | --- |
| `LF` | `PA8 / PA9` | `TIM1` |
| `LR` | `PC6 / PC7` | `TIM8` |
| `RF` | `PA6 / PA7` | `TIM3` |
| `RR` | `PA0 / PA1` | `TIM2` |

### 2.2 UART

USART3 使用 `PB10 / PB11`，公开测试文本包括：

```text
P0_STM32_UART_OK
P0_ENC LF=... LR=... RF=... RR=...
P0_STM32_RX_OK
```

UART 只使用 GND / TX / RX，不连接 5V。双方使用 3.3V TTL 电平，TX / RX 交叉连接。

## 3. 初次编码器结果与 LF 故障定位

新映射安全输出和编码器固件完成编译、烧录和基础输出验证后，`LR / RF / RR` 手动转轮计数通过，`LF` 初次无有效计数。

交叉测试结果：

| 测试 | 结果 | 说明 |
| --- | --- | --- |
| 已知正常 `LR` 编码器接 `LF` 输入 | `LF` 计数可变化 | `PA8 / PA9`、`TIM1` 和固件链路正常 |
| 可疑 `LF` 编码器接已知正常输入 | 仍无有效计数 | 故障随 `LF` 编码器侧移动 |

当时公开判断：`LF` 故障更可能位于电机内置编码器、内部连接器或电机编码器尾线侧，而不是 STM32 输入引脚或定时器配置。

## 4. LF 替换后复验

后续 `LF` 电机本体已替换。首次复测仍无变化；断电后重新压紧 `LF` 编码器供电 / 地线并重启系统，再次复测通过。

四路低功率手动转轮代表性结果：

| 电机 | 代表性结果 | 判定 |
| --- | ---: | --- |
| `LR` | `-3104 -> 6826`，总变化 `+9930` | 通过 |
| `RF` | 代表性变化 `+6328` | 通过 |
| `RR` | 代表性变化 `+9247` | 通过 |
| `LF` | `1 -> 22551`，总变化 `+22550` | 通过 |

`LF` 复测时，其余三路保持不变：

```text
START LF=1 LR=6816 RF=16589 RR=18604
END   LF=22551 LR=6816 RF=16589 RR=18604
DELTA LF=22550 LR=0 RF=0 RR=0
```

静止稳定性检查结果：

```text
first=(22551, 6816, 16589, 18604)
last=(22551, 6816, 16589, 18604)
delta=(0, 0, 0, 0)
samples=8
```

## 5. 当前结论

1. 四路编码器在低功率、人工手动转轮、UART 读数条件下均已产生有效计数。
2. `LF` 替换后编码器基础计数通过；后续异常更符合编码器供电 / 地线接触问题。
3. 第 4 路动力保险继续保持空置。
4. 该结果不表示主动动力测试、闭环控制、里程计、悬空动力或落地低速运动已经通过。
