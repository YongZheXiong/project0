# Hardware Reference Images

本目录存放 Project0 硬件实物图片、接口近景、安装参考图和底盘布局试摆图片。

图片用于辅助理解硬件外形、接口朝向、线束空间和安装关系，不替代 BOM、datasheet、实测尺寸或 CAD 设计输入。

## 目录说明

| 目录 | 放置内容 |
|---|---|
| `power/` | 主电池、主开关、保险座、保险盒、继电器、急停按钮、DC-DC、电源分配相关图片 |
| `compute/` | Orin NX、SSD、计算平台接口、散热和固定方式相关图片 |
| `control/` | STM32、电压采样、电流传感器、控制相关模块图片 |
| `sensing/` | Mid360、D435、传感器支架、传感器线缆相关图片 |
| `drive/` | 电机、电机驱动板、轮胎、联轴器、电机支架相关图片 |
| `wiring/` | 线材、端子、接插件、热缩管、线束固定件、标签相关图片 |
| `mechanical/` | 底盘板、立柱、螺丝、垫片、安装座、3D 打印件相关图片 |
| `layout/` | 多个硬件一起试摆、底盘总体布局、装车参考图、草图 |

## 命名建议

建议文件名包含 BOM `item_id`、硬件名称、视角和日期。

示例：

```text
PWR-001_main_battery_top_2026-05-26.jpg
PWR-MOT-004_motor_driver_connector_side_2026-05-26.jpg
LAYOUT_chassis_layer1_trial_layout_2026-05-26.jpg
```

## 使用规则

1. 单个硬件图片放入对应模块目录。
2. 多个硬件一起摆放、用于判断底盘布局的图片放入 `layout/`。
3. 涉及安装孔、接口、线缆出口或高度判断的图片，尽量带尺子、卡尺或螺丝作为尺度参考。
4. 关键尺寸仍应记录到 BOM 或对应 CAD 设计输入文件中，不能只依赖图片判断。
