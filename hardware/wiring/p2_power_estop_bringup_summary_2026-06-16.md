# P2 电源与急停上电验证摘要

> **历史记录**：本文是上一实车平台测试结果；新 H60 急停、电源和反供电必须按 H0-H8 重新验收。

## 1. 记录范围

本文记录 2026-06-16 完成的一轮 P2 电源分支、控制支路和急停动力切断验证。内容为公开技术摘要，不包含内部交接过程。

## 2. 已验证结果

1. 控制支路 DC-DC 输入端曾因剥线和压接接触不良导致输出链路为 `0V`；重新处理端子后，DC-DC 本体输出约 `5.12V`，STM32、ACS712 和编码器指示灯恢复。
2. 急停按钮使用 `NC` 触点控制继电器线圈。
3. 动力正极路径为：保险盒动力支路 → 继电器触点 → ACS712 → 动力分线端子 → 两块电机驱动器。
4. 急停未按下时，电驱 `P+ / P-` 可测得电池电压；按下急停后接近 `0V`。
5. 急停只切断动力支路，计算和控制支路不由急停直接断电。

## 3. USB 反供电现象

主电源关闭但 STM32 USB / 调试器仍连接时，电驱端曾测得约 `4.16V`，电驱指示灯仍可能点亮。拔掉 USB / 调试器后，电驱 `P+ / P-` 回到 `0V`。

当前边界：

1. 该现象按控制侧低电压反供电或残余供电处理，不作为继电器触点粘连的证据。
2. 判断整车动力是否真正断电，应同时关闭主电源并断开 STM32 USB / 调试器，再测量电驱输入。
3. 动力测试时优先使用车载控制支路给 STM32 供电。

## 4. 尚未完成

本次验证不表示线束最终固定、UART、编码器、ACS712 标定、长期温升或整车落地运动已经完成。
