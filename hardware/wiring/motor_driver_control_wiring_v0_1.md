# 电驱控制线接线与验证记录 v0.1

## 1. 文件作用

本文档记录 Project0 P2 装配阶段两块 WSDC2412D-V3.0 双通道直流有刷电机驱动器与 STM32F407VET6 控制板之间的控制线接线表、颜色分配、固件安全默认状态和当前验证结果。

本文档只覆盖电驱控制端 `VCC / GND / PWM / INA / INB`，不覆盖电驱动力端 `P+ / P-`、电机输出大电流线、编码器线、采样模块或 Orin NX 通信。

## 3. 数据手册结论

数据手册：

`hardware/reference_docs/drive/PWR-MOT-004_WSDC2412D-V3_0_datasheet.pdf`

关键结论：

1. 控制端 `VCC` 兼容 `3.3V` / `5V`；
2. 控制端 `VCC` 必须与控制信号高电平幅值相同；
3. `PWM / INA / INB` 输入信号悬空时为高电平；
4. `INA=H, INB=H` 为脱机；
5. `INA=L, INB=L` 为制动；
6. `INA=L, INB=H` 为正转；
7. `INA=H, INB=L` 为反转。

因此当前安全初始化不采用 `INA=0, INB=0` 作为默认状态，而采用：

```text
PWM = 0
INA = 1
INB = 1
电驱状态 = 脱机
```

## 7. 已完成检查

### 7.1 不上电通断 / 短路检查

| 检查项 | 结果 |
|---|---|
| STM32 `3.3V` 与 `GND` | 蜂鸣档不响，曾显示约 `0.731V` 压降 |
| 电驱控制端 `VCC` 与 `GND` | 蜂鸣档不响，曾显示约 `0.419V` 压降 |
| 控制线端到端导通 | 用户确认正常 |
| 相邻信号短路 | 未发现异常 |

### 7.2 数据手册确认前的观测

| 条件 | 观测 | 后续解释 |
|---|---|---|
| 电驱控制端 `VCC` 接 STM32 `3.3V`，STM32 未安全初始化 | 多数 `PWM / INA / INB` 稳定约 `2.9-3.3V` | 数据手册说明输入悬空为高电平 |
| 断开两块电驱控制端 `VCC` | `PWM` 约 `0V`，其他约 `1V` | 未供电/悬空状态，不作为逻辑判断 |

### 7.3 安全初始化后实测

实测条件：

1. 主电池未接；
2. 电驱动力端 `P+ / P-` 未接；
3. STM32 安全初始化固件已烧录并处于运行状态；
4. 两块电驱控制端 `VCC` 红线已接 STM32 `3.3V`；
5. 两块电驱控制端 `GND` 已接 STM32 `GND`。

实测结果：

| 测点 | 目标 | 结果 |
|---|---|---|
| 两块电驱 `VCC` | 约 `3.3V` | 符合 |
| 两块电驱 `GND` | `0V` | 符合 |
| 两块电驱 `PWM1 / PWM2` | 约 `0V` | 符合 |
| 两块电驱 `INA / INB` | 约 `3.3V` | 符合 |

当前结论：

```text
控制线接入和 STM32 安全初始化验证通过。
当前电驱控制状态为 PWM=0, INA=H, INB=H，即脱机。
```

### 7.4 单电机低占空比短脉冲测试

共同测试条件：

1. 一次只测试一个电机；
2. 四个轮子悬空；
3. 用户全程人工看守；
4. 急停机械安装仍未完成，因此只允许短时低占空比测试；
5. 测试固件为临时固件，不作为正式底盘控制固件；
6. 每次测试后烧回安全初始化状态。

实测电机输出接线：

| 电机 | 电驱通道 | 电机动力线 |
|---|---|---|
| 左前 LF | DRV-L `M1 / CH1` | 红线 -> `M1A`；白线 -> `M1B` |
| 左后 LR | DRV-L `M2 / CH2` | 红线 -> `M2A`；白线 -> `M2B` |
| 右前 RF | DRV-R `M2 / CH2` | 红线 -> `M2A`；白线 -> `M2B` |
| 右后 RR | DRV-R `M1 / CH1` | 红线 -> `M1A`；白线 -> `M1B` |

阶段诊断：

| 检查项 | 结果 |
|---|---|
| `PB6` 普通 GPIO 高电平输出，保持约 `10s` | STM32 端和 DRV-L `PWM1` 端均正常 |
| `TIM4_CH1` / `PB6` 约 50% PWM 输出 | DRV-L `PWM1` 端正常 |
| `PB7` 普通 GPIO 高电平输出，保持约 `10s` | DRV-L `PWM2` 端正常 |
| `PB8` 普通 GPIO 高电平输出，保持约 `10s` | DRV-R `PWM1` 端正常 |
| DRV-R `INA1 / INB1` 方向诊断 | `INA1` 可拉低到约 `0.18V`，`INB1` 约 `3.3V`，符合方向控制预期 |

短脉冲测试行为：

| 项目 | 设置 |
|---|---|
| PWM 通道 | 目标电机对应 `TIM4_CH1` 到 `TIM4_CH4` 中的一路 |
| 比较值 | `8` |
| 估算占空比 | 约 `14%` 到 `15%` |
| 持续时间 | 约 `500ms` |
| 方向状态 | `INA=L, INB=H` |
| 测试后状态 | `PWM=0, INA=H, INB=H` |

测试结果：

| 电机 | 实际通道 | 结果 |
|---|---|---|
| `LF` | DRV-L `M1 / CH1` | 通过 |
| `LR` | DRV-L `M2 / CH2` | 通过 |
| `RF` | DRV-R `M2 / CH2` | 通过 |
| `RR` | DRV-R `M1 / CH1` | 通过 |

边界：

```text
当前只验证四个电机能分别在低占空比短脉冲下转动。
不表示方向一致性、编码器读取、整车落地运动或正式控制固件已完成。
```

### 7.5 主输入保险熔断与端子修复

`LR` 测试准备过程中曾出现疑似打火 / 噼啪声，后续定位到：

1. 电源开关输入端端子在移动第三层底板时松脱；
2. 主输入 25A ATO / ATC 保险丝熔断，保险丝本体测得 `OL`；
3. 用户更换电源开关输入端端子；
4. 用户更换同规格 25A ATO / ATC 主输入保险丝；
5. 修复后断电检查、短时上电观察和左右电驱动力输入恢复正常。

该问题说明主输入保险起到了异常保护作用，也说明线束防拉扯和端子固定仍需后续整理。

### 7.6 悬空同侧联动与四轮联动测试

在四个单电机低占空比短脉冲测试通过后，继续进行了悬空同侧联动和四轮联动测试。

初始联动时曾沿用单电机阶段参数：

| 项目 | 初始值 |
|---|---|
| 比较值 | `8` |
| 估算占空比 | 约 `14%` 到 `15%` |
| 持续时间 | 约 `500ms` |

当时现象为：

1. `LF` 在左侧联动中不转；
2. `LR` 可转；
3. 右侧两个轮子可转，但方向与左侧相反。

后续针对 `LF` 执行了以下诊断：

1. 左电驱 `P+ / P-` 供电、左侧支路保险和 `LF` 动力线通断复核通过；
2. 仅控制端上电时，`PB6 -> DRV-L PWM1` 诊断测得约 `3.26V`，控制线通过；
3. `PD0 / PD1 -> DRV-L INA1 / INB1` 方向诊断通过；
4. `PB6` 作为普通 GPIO 直拉高的极短脉冲可驱动 `LF` 起转；
5. `TIM4_CH1` 走正常 PWM 路径、接近 `100%` 占空比的极短脉冲同样可驱动 `LF` 起转。

阶段判断：

```text
LF 问题不是硬件损坏，也不是 TIM4_CH1 故障。
更符合 LF 在联动场景下的低占空比起转门槛高于 compare=8 的保守参数。
```

最终联动测试参数调整为：

| 项目 | 最终值 |
|---|---|
| 比较值 | `20` |
| 估算占空比 | 约 `36%` |
| 持续时间 | 约 `200ms` |
| 启动等待 | 约 `5s` |
| 分阶段间隔 | 约 `8s` |

方向补偿口径：

1. 左侧保持 `INA=L, INB=H`；
2. 右侧在当前测试固件中采用 `INA=H, INB=L` 反向补偿，以符合“从车尾向车头看，朝车头方向为正方向”的定义。

最终结果：

| 阶段 | 结果 | 方向 |
|---|---|---|
| 左侧 `LF + LR` | 通过 | 均朝正方向 |
| 右侧 `RF + RR` | 通过 | 反向补偿后均朝正方向 |
| 四轮同时短脉冲 | 通过 | 四轮均朝正方向 |

测试结束后，STM32 已重新烧回安全初始化状态。

## 9. 下一步

本轮四个单电机短脉冲测试、悬空同侧联动和四轮联动测试已完成。测试收尾时原 STM32 曾烧回安全初始化；2026-06-17 后续确认原板 3.3V 与 NRST 异常，因此该历史收尾动作不代表故障板当前仍在运行或维持安全输出。

后续若进入编码器验证、急停闭环或整车落地动力测试，应重新满足：

1. 轮子悬空；
2. 只开放计划测试的电机通道；
3. 先确认电驱 `P+ / P-` 极性、保险路径和电机输出端；
4. 启动默认保持 `PWM=0, INA=H, INB=H`；
5. 正式固件起步参数应考虑 `LF` 联动场景下的最低有效占空比，不能直接默认沿用 `compare=8`；
6. 观察编码器方向、噪声、电驱指示灯、线束发热和异常保护；
7. 急停链路完成前不做无人看守或落地动力测试；
8. 固件必须采用当前右侧实物映射：`RF = DRV-R M2 / PB9 / PD6 / PD7`，`RR = DRV-R M1 / PB8 / PD4 / PD5`；
9. 若继续沿用当前方向定义，则右侧需保留软件反向补偿或重新改线后再验证。
