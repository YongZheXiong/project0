# H60 重建版电源接线基线 v0.2

> 状态：正式设计输入 / 尚未实装
> 依据：当前 H60 + MC520 数字基线与公开验收门
> 边界：本文不是现场已接线记录；任何物理接线前必须断电、拆除电池并按实物针序复核

## 1. 当前电源树

```text
PWR-001 3S battery (+)
-> PWR-006 25A main fuse
-> PWR-003 external main switch
-> fused distribution positive input

Branch A: H60 fuse -> H60 J1 (+)
Branch B: Orin fuse -> COMP-001 IN+ -> 12V OUT -> C1902 DC5525 center (+)
Branch C: Mid360 fuse -> SENS-009 IN+ -> 12V OUT -> Mid360 (+)

Common negative bus:
battery (-), H60 J1 (-), COMP-001 IN-, SENS-009 IN-
```

当前只保留主保险、主开关和 H60/Orin/Mid360 三条支路保护。支路保险额定值必须由线径、端子、器件输入范围以及稳态/峰值测量冻结，不得直接照搬旧平台路号或旧四支路建议值。

## 2. 当前明确不接入的器件

- 独立急停按钮及其 NC/NO 触点；
- 急停继电器/接触器和线圈支路；
- Orin 急停反馈 GPIO；
- Keyes 外置电压模块；
- ACS712 或其他车载电流采样模块；
- 旧 STM32、WSDC、CTRL-001 和六路保险盒既有路号。

旧平台器件可以保留为备件或历史证据，但不得接入 H60 新车当前线束。主开关用于整车断电，不得标记为急停。

## 3. H60 与四套电机

四套 MC520P56 使用配套 XH2.54 六芯线分别接入 H60 的四路电机/编码器端口。电机端目标定义为：

| Pin | 信号 |
| ---: | --- |
| 1 | Motor - |
| 2 | Encoder VCC |
| 3 | Encoder A |
| 4 | Encoder B |
| 5 | Encoder GND |
| 6 | Motor + |

装车前必须对每根线完成针序、通断、Motor ±、Encoder VCC/GND 和 A/B 核对。安装方向带来的符号差异通过低能量、单通道、架空测试确定，不允许只凭线色猜测。

## 4. Orin–H60 UART

基本连接为 `TX <-> RX`、`RX <-> TX`、`GND <-> GND`。H60 或 Orin 可能因支路故障、维护、开关顺序或启动时序形成单侧上电，因此永久连接前必须：

1. 分别验证 H60 断电/Orin 上电和 Orin 断电/H60 上电；
2. 测量对方电源轨与 UART 引脚是否被抬高，并记录反灌电流；
3. 必要时采用任一侧掉电时输出高阻的双电源缓冲或数字隔离；
4. 验证任一侧重启或链路恢复后都保持 `DISARMED`，不能恢复旧命令。

反供电门未关闭前，不得把直连 UART 制作为永久运动线束。

## 5. 电压采样

当前车载采样只有 H60 `PC0` 板载 VIN ADC。它必须经过多点校准，记录原始 ADC、参考仪表电压、拟合参数、误差和校准版本。该通道测量 H60 上电期间的支路 VIN；H60 失电期间没有独立电池观测通道。

当前没有车载电流采样。外部钳形表或合规功率分析仪可以在台架调试时测量电流，但不属于车载功能，也不能产生持续电流遥测声明。

## 6. 上电前检查

- 电池、25A 主保险、主开关、分配节点和三条支路与图一致；
- 各支路保险、线径、端子、极性和器件输入范围可追溯；
- H60、Orin、Mid360 没有经错误端口互相供电；
- 无继电器线圈、急停触点、ACS712 或旧采样小板残留在当前链路；
- UART 单侧掉电门已通过，或在该门前保持断开；
- 所有线束具备标识、绝缘、应力释放和裸露导体检查；
- 首次 H60 上电优先使用限流电源且不接电机；
- 首次电机测试车辆可靠架空、轮周净空、低占空比、人工持续监看，主开关可直接触达。

本文是数字接线基线；实物接线、上电和运动分别由 H2-H8 验收记录确认。
