# P2 STM32 3.3V 供电故障摘要

## 1. 故障现象

2026-06-17，在继续 USART3 最小通信测试前，WCH-Link / CMSIS-DAP 已能被 OpenOCD 识别，但无法读取 STM32 目标芯片 ID。

隔离检查确认：

1. 车上控制支路 5V 输入正常；
2. 外接控制线拔除后，5V / 3.3V 对地未发现硬短路；
3. 板载 3.3V 仅为零点几伏；
4. `RESET / NRST = 0V`；
5. Type-C 单板供电时，5V 和 3.3V 同样明显异常。

## 2. 当前判断与安全边界

当前阻塞点是原 STM32 控制板板载 3.3V 供电故障，不再按“仅缺少烧录工具或 UART 配置”处理。

在替换板完成验收前：

1. 不向故障板外灌 3.3V；
2. 不继续 USART3 烧录；
3. 不恢复动力保险和运动测试；
4. 不声明故障板仍在运行任何固件。

## 3. 后续验收顺序

替换板到位后依次验证：

1. Type-C 单板供电下的 5V、3.3V 和 RESET；
2. 车载控制支路 5V 供电；
3. WCH-Link / CMSIS-DAP + OpenOCD 的 SWD 连接；
4. USART3 最小发送；
5. Orin NX 串口接收；
6. 编码器和后续底盘控制。
