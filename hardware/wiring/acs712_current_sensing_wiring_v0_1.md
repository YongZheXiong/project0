# ACS712-30A 电流采样接线记录 v0.1

## 1. 文件作用

本文档记录 Project0 P2 装配阶段 `CTRL-005 ACS712-30A` 动力支路总电流检测模块与 STM32 之间的接线方式，重点说明 ACS712 信号侧分压滤波小板的材料、洞洞板布局、焊接节点和检查方法。

本文档不替代 DEC-035、正式底盘控制固件、ADC 标定记录或 P2 电流采样测试记录。

## 2. 接入边界

ACS712-30A 大电流端串入动力支路正极：

```text
PWR-MOT-003 继电器 87
-> CTRL-005 ACS712-30A 电流传感器模块
-> 动力分线端子
-> 两块电机驱动板 P+
```

ACS712 信号侧接入 STM32：

```text
ACS712 V -> 控制支路 5V
ACS712 G -> STM32 GND / 控制侧 GND
ACS712 S -> 分压滤波小板 -> STM32 PA1 / ADC
```

重要边界：

```text
ACS712 S 不得直接接 STM32 ADC。
ACS712 S 也不得接 3.3V。
```

原因：ACS712-30A 在 5V 供电时，零电流输出约 `2.5V`，正向大电流时可能高于 STM32 ADC 的 `0V-3.3V` 输入范围。因此必须先分压，再接 STM32 ADC。

当前分配口径：

| 信号 | STM32 引脚 | 说明 |
|---|---|---|
| 动力支路电流采样 | `PA1` | ACS712 S 经分压滤波后接入 |
| 主电池电压采样 | `PA0` | 预留给 `CTRL-004` 电压检测模块 |

## 3. 分压滤波电路

首版分压滤波电路：

```text
ACS712 S ---- 12k ----+---- STM32 PA1
                      |
                     22k
                      |
                     GND

STM32 PA1 点 ---- 0.1uF ---- GND
```

分压比例约为：

```text
22k / (12k + 22k) ~= 0.647
```

估算电压：

| 状态 | ACS712 S 原输出 | STM32 PA1 分压点 |
|---|---:|---:|
| 0A | 约 `2.50V` | 约 `1.62V` |
| +30A | 约 `4.48V` | 约 `2.90V` |
| -30A | 约 `0.52V` | 约 `0.34V` |

`0.1uF` 电容用于简单 RC 滤波。若现场暂时没有电容，可以先只焊 `12k + 22k` 分压，电容后补；但分压不应省略。

## 4. 材料清单

| 材料 | 数量 | 要求 |
|---|---:|---|
| 剪好的洞洞板 | 1 小块 | 建议至少 `3 列 x 4 行` |
| `12kΩ` 插件电阻 | 1 | 1/4W，1% 或 5% 均可 |
| `22kΩ` 插件电阻 | 1 | 1/4W，1% 或 5% 均可 |
| `104` 陶瓷电容 | 1 | `0.1uF`，50V 可用，无正负极 |
| 2.54mm 排针 / 杜邦公针 | 3 个信号位 | `S_IN`、`PA1_OUT`、`GND` |
| 小信号线 / 杜邦线 | 若干 | 连接 ACS712 与 STM32 |
| 热缩管 / 绝缘材料 | 若干 | 包覆小板和焊点 |
| 扎带 / 双面胶 / 绝缘固定件 | 若干 | 固定小板，避免焊点受力 |

电阻和 `104` 陶瓷电容均无正负极。

## 5. 三列四行洞洞板布局

### 5.1 坐标定义

洞洞板正面看，定义 `3 列 x 4 行`：

```text
A1   B1   C1
A2   B2   C2
A3   B3   C3
A4   B4   C4
```

节点定义：

```text
A 列 = S_IN
B 列 = ADC_NODE / PA1_OUT
C 列 = GND
```

洞洞板默认每个孔彼此不连通，因此焊接时必须在背面把同一列连成节点：

```text
A1-A2-A3-A4 连成 S_IN
B1-B2-B3-B4 连成 ADC_NODE
C1-C2-C3-C4 连成 GND
```

建议用剪下来的电阻脚或短导线做背面跳线，不建议新手只靠大面积焊锡桥。

### 5.2 元件插孔表

| 元件 / 线 | 第 1 脚 | 第 2 脚 | 说明 |
|---|---|---|---|
| `12kΩ` 电阻 | `A1` | `B1` | ACS712 S 到 ADC 节点的上分压电阻 |
| `22kΩ` 电阻 | `B2` | `C2` | ADC 节点到 GND 的下分压电阻 |
| `104` 电容 | `B3` | `C3` | ADC 节点到 GND 的滤波电容 |
| ACS712 S 输入排针 / 线 | `A4` | 无 | 标记为 `S_IN` |
| STM32 PA1 输出排针 / 线 | `B4` | 无 | 标记为 `PA1_OUT` |
| GND 排针 / 线 | `C4` | 无 | 标记为 `GND` |

正面逻辑：

```text
A1 -- 12k -- B1
B2 -- 22k -- C2
B3 -- 104 -- C3
A4 = S_IN
B4 = PA1_OUT
C4 = GND
```

背面跳线：

```text
A1-A2-A3-A4
B1-B2-B3-B4
C1-C2-C3-C4
```

完成后，等效连接为：

```text
ACS712 S
-> A4
-> A 列跳线
-> A1
-> 12k
-> B1
-> B 列跳线
-> B4
-> STM32 PA1
```

同时：

```text
B 列 ADC_NODE -> 22k -> C 列 GND
B 列 ADC_NODE -> 104 -> C 列 GND
```

## 6. 接口建议

建议小板上使用排针，方便和现有杜邦母头连接：

| 接口 | 排针 | 用途 |
|---|---|---|
| ACS 输入侧 | `1P` 公针 | `S_IN`，接 ACS712 `S / OUT` |
| STM32 输出侧 | `2P` 公针 | `PA1_OUT + GND`，接 STM32 `PA1 + GND` |

也可以使用 `3P` 公针：

```text
S_IN | PA1_OUT | GND
```

若使用 `3P` 公针，必须在线束两端清楚标识，避免把 ACS712 S、STM32 PA1 和 GND 插错。

## 7. 焊接步骤

1. 剪一小块洞洞板，至少保留 `3 列 x 4 行`。
2. 按坐标插入 `12kΩ`：`A1 -> B1`。
3. 按坐标插入 `22kΩ`：`B2 -> C2`。
4. 按坐标插入 `104` 电容：`B3 -> C3`。
5. 插入或焊接 `S_IN`：`A4`。
6. 插入或焊接 `PA1_OUT`：`B4`。
7. 插入或焊接 `GND`：`C4`。
8. 背面用短导线 / 剪下来的元件脚连通 `A1-A2-A3-A4`。
9. 背面连通 `B1-B2-B3-B4`。
10. 背面连通 `C1-C2-C3-C4`。
11. 检查背面焊点，确保 A、B、C 三列之间没有意外短路。

`22kΩ` 和 `104` 电容是并联关系，不需要叠在一起焊；它们分别占用 `B2-C2` 和 `B3-C3`，但两端通过 B 列和 C 列跳线接到同一对节点。

## 8. 万用表检查

焊完后先不上电，使用欧姆档检查：

| 测量点 | 预期 |
|---|---|
| `A4` 到 `B4` | 约 `12kΩ` |
| `B4` 到 `C4` | 约 `22kΩ` |
| `A4` 到 `C4` | 约 `34kΩ` |
| A 列任意两个孔 | 接近 `0Ω` |
| B 列任意两个孔 | 接近 `0Ω` |
| C 列任意两个孔 | 接近 `0Ω` |
| A 列到 C 列 | 不应接近 `0Ω` |
| B 列到 C 列 | 不应接近 `0Ω`，应约 `22kΩ` |

如出现接近 `0Ω` 的异常短路，不得上电。

## 9. 上电验证

首次上电时，先不要把 `PA1_OUT` 接入 STM32，只接：

```text
ACS712 V -> 5V
ACS712 G -> GND
ACS712 S -> 小板 S_IN
小板 GND -> GND
```

上电后用万用表测量：

| 测量点 | 预期 |
|---|---|
| ACS712 S / 小板 `S_IN` 对 GND | 零电流附近约 `2.5V` |
| 小板 `PA1_OUT` 对 GND | 零电流附近约 `1.6V` |

确认 `PA1_OUT` 电压低于 `3.3V` 后，断电，再连接：

```text
小板 PA1_OUT -> STM32 PA1
小板 GND -> STM32 GND
```

## 10. 固定要求

分压滤波小板不得悬空晃动。完成检查后，应至少满足：

1. 小板背面焊点不接触底盘、螺丝、保险盒金属件或其他裸线。
2. 小板用热缩管、绝缘胶带或绝缘外壳包覆。
3. 小板通过扎带、双面胶或绝缘固定件固定在第二层线束附近。
4. `S_IN`、`PA1_OUT`、`GND` 三根线都有标签或颜色区分。
5. 线束移动时，焊点不承受拉力。
