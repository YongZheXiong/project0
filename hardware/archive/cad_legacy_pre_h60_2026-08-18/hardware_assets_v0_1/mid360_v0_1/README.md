# Livox Mid-360 v0.1

状态：v0.1 单件 CAD 资产已归档，用于顶部激光雷达安装和视野验证。

## 文件

1. `source/livox_mid360_v0_1.f3d`：Fusion 360 可编辑源文件。
2. `final/livox_mid360_v0_1.step`：STEP 交换文件，后续装配优先使用。
3. `preview/livox_mid360_v0_1.stl`：STL 预览和包围盒检查文件。

## 来源

1. 原始导出目录：`<本地CAD导出目录>/`
2. 原始文件名前缀：`mid-360`
3. 建模方式：用户在 Fusion 360 中导入/整理并导出。

## 尺寸检查

1. STL 三角面数量：`168568`。
2. STL 包围盒约为 `72.737 x 60.097 x 64.874 mm`。
3. STEP 单位为 mm。
4. STEP 检测到 `6` 个实体 BREP、`9` 个 closed shell 和 `1543` 个 advanced face。

## 使用说明

1. 用于 Mid-360 顶部安装高度、安装支架、线缆走向和视野遮挡验证。
2. 当前模型不包含完整线缆弯折包络。
3. 后续应配合 Mid-360 FOV 模型或视场草模检查雷达视野是否被 D435、Orin、开关或上层结构遮挡。
