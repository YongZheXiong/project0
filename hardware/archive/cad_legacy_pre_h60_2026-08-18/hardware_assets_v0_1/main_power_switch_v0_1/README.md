# Main Power Switch v0.1

状态：v0.1 单件 CAD 资产已归档，用于主电源旋钮开关尾部空间和安装位置验证。

## 文件

1. `source/main_power_switch_v0_1.f3d`：Fusion 360 可编辑源文件。
2. `final/main_power_switch_v0_1.step`：STEP 交换文件，后续装配优先使用。
3. `preview/main_power_switch_v0_1.stl`：STL 预览和包围盒检查文件。

## 来源

1. 原始导出目录：`<本地CAD导出目录>/`
2. 原始文件名前缀：`电源旋钮开关`
3. 建模方式：用户在 Fusion 360 中按实物外形建模并导出。

## 尺寸检查

1. STL 三角面数量：`7534`。
2. STL 包围盒约为 `45.488 x 45.4 x 45.494 mm`。
3. STEP 单位为 mm。
4. STEP 检测到 `1` 个实体 BREP、`1` 个 closed shell 和 `51` 个 advanced face。

## 使用说明

1. 用于第二层尾部主电源旋钮开关安装位置、面板下方深度和大电流线端子空间验证。
2. 主电源开关应与急停分置尾部两侧，保证可触达和可区分。
3. 当前模型不替代主电源接线、绝缘、防松和防拉扯设计。
