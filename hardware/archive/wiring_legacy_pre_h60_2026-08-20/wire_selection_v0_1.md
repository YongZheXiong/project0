# Project0 上一平台实装线束与连接边界

> **历史记录**：本文线束适用于上一 STM32/JGB/WSDC 平台。H60 重建线束按 [当前接线基线](../../wiring/h60_power_wiring_v0_2.md) 重新定额和验收。

## 1. 文件作用

> 文档状态：历史 / 上一平台实装线束事实源
> 最近更新：2026-06-18

本文档记录 Project0 当前实装线材、线径、端子、连接端点和仍待验证的线束边界。文件名保留 `v0_1` 以避免破坏既有引用，但正文已由 P1.3 采购口径升级为 P2 实装事实源。

本文档不是完整原理图，也不表示所有线束固定、通断、极性、温升和跌落后复验已经通过。具体现场故障、测量值和分阶段验证结果仍以 `hardware/wiring/` 下对应原始记录及 P2 验收清单为准。

## 2. 适用边界

1. 主电池为 3S 主电池。
2. 主输入保险首版按 25A ATO / ATC 保险丝边界处理。
3. 分路保险盒提供主开关后的正极分路和负极汇流。
4. 急停按钮只控制继电器线圈，不承载电机动力大电流。
5. ACS712-30A 电流检测模块串在继电器之后、电机驱动板之前的动力正极路径上。
6. 电压检测模块为并联采样，不串入主电源回路。
7. 电机动力线和编码器线优先保留电机原厂自带线；如需延长，按本文档补线。
8. Orin NX 与 STM32 UART 只连接 GND / TX / RX，不连接 5V。
9. UART 屏蔽裸线按单端接地处理，不作为 GND / TX / RX 三根芯线之一。

### 5.7 采样和控制信号

| 起点 | 终点 | 线径 | 颜色 | 备注 |
|---|---|---|---|---|
| 主电源正负采样点 | 电压检测模块输入 | 22AWG | 现有多色线 | 并联采样，不串入主电源回路 |
| 电压检测模块 VCC / GND / OUT | STM32 | 22AWG | 现有多色线 | OUT 接 STM32 ADC，按后续分压/滤波方案执行 |
| ACS712 VCC / GND / OUT | STM32 | 22AWG | 现有多色线 | ACS712 大电流端和信号端分开理解；`S / OUT` 必须经分压滤波后接 STM32 `PA1`，详见 `acs712_current_sensing_wiring_v0_1.md` |
| STM32 PWM / INA / INB / GND | 两块电驱控制端 | 22AWG | 现有多色线 | 端子形式按电驱 CN1 和 STM32 排针确定 |
| 电机编码器 VCC / GND / A / B | STM32 编码器输入 | 原厂线 / 后续可选 24AWG 四芯屏蔽软线 | 原厂颜色 / 屏蔽线 | 本轮未采购四芯屏蔽线；若原厂线长度不足，再按实物长度补买 |

JGB-520 编码器线序按当前 BOM 与实物照片收束为：蓝色为编码器 `VCC / +5V`，黑色为编码器 `GND / 0V`，黄色为 `C1 / A`，绿色为 `C2 / B`；红色和白色为电机动力线，不接入 STM32 编码器输入。

四个电机编码器 A/B 信号线接入 STM32 的 P2 决定如下：

| 电机 | 黄色 `C1 / A` | 绿色 `C2 / B` | STM32 定时器资源 |
|---|---|---|---|
| 左前 `LF` | `PA8` | `PA9` | `TIM1_CH1 / TIM1_CH2` |
| 左后 `LR` | `PA6` | `PA7` | `TIM3_CH1 / TIM3_CH2` |
| 右前 `RF` | `PC6` | `PC7` | `TIM8_CH1 / TIM8_CH2` |
| 右后 `RR` | `PA15` | `PB3` | `TIM2_CH1 / TIM2_CH2` |

固件配置时 `PA15 / PB3` 需释放 JTAG 复用，仅保留 SWD 调试；编码器信号接入前应确认 A/B 输出电平不超过 STM32 输入允许范围。

上一平台电驱控制线实际接线、颜色分配、STM32 引脚分配和安全初始化验证结果见 `motor_driver_control_wiring_v0_1.md`。

ACS712-30A 电流采样分压滤波小板采用 `3 列 x 4 行` 洞洞板布局：A 列为 `S_IN`，B 列为 `ADC_NODE / PA1_OUT`，C 列为 `GND`；`12kΩ` 接 `A1-B1`，`22kΩ` 接 `B2-C2`，`104 / 0.1uF` 电容接 `B3-C3`，`A4 / B4 / C4` 分别作为 `S_IN / PA1_OUT / GND` 接口。

### 5.8 Orin NX 与 STM32 UART

| 起点 | 终点 | 线径 | 端子 | 备注 |
|---|---|---|---|---|
| Orin NX / C1902 GND | STM32 GND | 24AWG 三芯屏蔽软线 | 2.54mm 杜邦母头 3P 胶壳 | 必须共地 |
| Orin NX / C1902 TX | STM32 RX | 24AWG 三芯屏蔽软线 | 2.54mm 杜邦母头 3P 胶壳 | TX/RX 交叉 |
| Orin NX / C1902 RX | STM32 TX | 24AWG 三芯屏蔽软线 | 2.54mm 杜邦母头 3P 胶壳 | TX/RX 交叉 |

三芯屏蔽线的裸线为屏蔽线，不是第四根通信芯线。当前屏蔽线处理口径为单端接地：一端悬空并绝缘，另一端接系统 GND，可接 Orin NX DC-DC 输出负极或同系统地。不得把屏蔽线两端同时接地，也不得把 TX / RX 错接到 GND。

### 5.9 急停 NO 状态反馈

急停按钮 `NO` 只作为 STM32 状态反馈，不参与动力切断。

当前口径：

| 起点 | 终点 | 线径 | 备注 |
|---|---|---|---|
| STM32 急停状态输入 GPIO | 急停按钮 `NO` 一端 | 22AWG | GPIO 配置输入 + 内部上拉 |
| 急停按钮 `NO` 另一端 | 控制支路 DC-DC 负极 / STM32 GND | 22AWG | 按下急停后 GPIO 被拉低 |

注意：`NO` 不接 12V，不接保险盒正极，不接继电器 `85 / 86`。当前仍需最终确认实际接入的 STM32 GPIO 引脚并同步固件。

## 7. 装配验证要求

1. 上电前必须逐段检查极性、通断和短路。
2. 所有大电流端子必须做机械拉力检查，不得裸线缠绕或虚压。
3. 主输入、动力支路、Orin NX 支路、Mid360 支路和控制支路应分区走线并做线号标识。
4. 电机动力线与编码器 / UART / ADC 采样线避免长距离紧贴并行。
5. P2 首次上电后应检查主电源入口、保险座、继电器、ACS712、电驱输入端、DC-DC 输入输出端和端子处温升。
