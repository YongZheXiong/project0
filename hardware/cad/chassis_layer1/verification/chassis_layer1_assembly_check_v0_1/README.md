# Chassis Layer 1 Assembly Check v0.1

状态：v0.1 第一层底板装配验证快照已归档。

本目录保存用户在 Fusion 360 中建立的第一层底板装配验证模型。该模型基于真实左右轮系装配、第一层底板边缘缺口、核心硬件占位和当前 v0.1 参数，用于检查第一层底板与轮系、电机支架、电池、保险盒和电驱之间的空间关系。

当前验证基准：

1. 轮距：`175 mm`。
2. 轴距：`180 mm`。
3. 第一层底板外形：约 `270 x 208.4 mm`。
4. 轮胎边缘缺口：`70 x 40 mm, R6`。
5. 电机安装在第一层底板下方。
6. 电机支架安装面贴第一层底板下表面。
7. 电池、保险盒和电驱当前仍按第一层上方占位验证。

检查结论：

1. 整体没有明显结构冲突，当前尺寸可以相互兼容。
2. 以当前底板尺寸和轮系位置看，两块电驱放在第一层上方时更容易被挤到最前端或最后端，不利于理想的中部两侧布局。
3. 由于四轮边缘缺口和 `270 mm` 底板长度，底板最前端和最后端剩余窄边较小；角部立柱如果放在这些区域，刚度和抗晃能力可能不足，亚克力板风险更明显。
4. 当前第一层空间基本刚好容纳电池、保险盒、电驱和下方电机模块；第二层必须同步验证剩余硬件和线束空间。

下一轮建议：

1. 第一层底板长度从 `270 mm` 试增到 `290-300 mm`，提高前后窄边和角部立柱孔位余量。
2. 优先验证两块电驱安装在第二层底板下方的方案。
3. 第一层底板下方安装电驱可作为备选，但需重点检查离地、轮胎、电机、线束、防护和维护问题。
4. 同步建立第二层布局验证，确认 STM32、Orin NX、Orin NX DC-DC、控制支路 DC-DC、Mid360 DC-DC、急停、主电源开关和线束路径是否可容纳。

归档文件：

1. `source/chassis_layer1_assembly_check_v0_1.f3z`：Fusion 360 装配验证源文件。
2. `final/chassis_layer1_assembly_check_v0_1.step`：装配验证交换文件。
3. `preview/chassis_layer1_assembly_check_v0_1.stl`：装配验证预览文件。

验证记录：

1. STEP 文件头有效，由 Autodesk Translation Framework 导出。
2. STEP 文件包含 `10` 个 `MANIFOLD_SOLID_BREP`。
3. STL 文件为有效二进制 STL，三角面数量为 `19660`。
4. STL 包围盒约为 `208.4 x 138.173 x 270.0 mm`。
