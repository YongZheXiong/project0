# Chassis Layer 1 CAD

状态：历史验证资料。第一层底盘 v0.1 CAD 草模入口已保留，但不再作为当前最终加工基线。

当前最终加工基线已由 `../chassis_three_layer_freeze_v0_1/` 承接。本目录仅用于追溯早期第一层底盘草模、参考尺寸和装配验证过程。

本目录用于存放 Project0 第一层底盘的 CAD 设计输入、参考尺寸图、建模源文件、预览文件和最终导出文件。

当前目录结构：

1. `design_inputs.md`
   - 第一层底盘 CAD 建模参数输入表。

2. `reference_drawings/`
   - 商家尺寸图、孔位图、安装尺寸图和必要的尺寸参考图。

3. `source/`
   - Fusion 360 / OpenSCAD / 其他参数化建模源文件。
   - `fusion_auto_model_chassis_layer1_v0_1.py`：Fusion 360 Python 草模脚本，用于检查第一层底板外形、四轮边缘缺口、轮系占位、电机支架孔位和第一层核心硬件占位关系。

4. `preview/`
   - 草模、预览 STL 或中间检查文件。

5. `final/`
   - 最终确认后导出的 CAD 交付文件。

6. `verification/chassis_layer1_assembly_check_v0_1/`
   - 第一层底板装配验证快照 v0.1。
   - 用于记录当前 `270 x 208.4 mm` 底板、`180 mm` 轴距、`175 mm` 轮距和真实轮系装配下的兼容性检查结果。

当前说明：

1. `fusion_auto_model_chassis_layer1_v0_1.py` 只是空间验证草模，不是加工图。
2. 底板初值为 `270 x 208.4 x 3 mm`，宽度按 `175 mm` 轮距与 `33.4 mm` 轮胎宽度对齐。
3. 四个轮胎避让结构为左右边缘缺口，初值为 `70 x 40 mm, R6`。
4. 草模中硬件位置用于观察碰撞、余量和线束方向，正式孔位仍需实物复核。
5. 装配验证快照显示当前尺寸总体可兼容，但电驱位置、前后窄边立柱刚度和第二层剩余硬件布局需进入下一轮验证。
6. 第二层底板与电驱下挂布局验证入口见 `../chassis_layer2/`；下一轮第一层长度优先按 `290 mm` 验证，`300 mm` 作为更宽裕备选。
