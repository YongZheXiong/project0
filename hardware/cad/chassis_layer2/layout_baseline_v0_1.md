# 第二层底板布局基准草案 v0.1

状态：草案，待人工确认和 CAD 草模验证。

本文基于第一层底板装配验证结论和 `design_inputs.md` 推导第二层底板 v0.1 的布局验证基准。本文不表示 CAD 已完成，也不代表最终加工方案。

---

## 1. 坐标约定

1. 与第一层底板保持同一平面坐标约定。
2. `X` 轴为车体前后方向，正方向为车头。
3. `Y` 轴为车体左右方向，正方向为车体左侧。
4. 原点建议与第一层底板几何中心对齐。
5. 单位均为 mm。

---

## 2. 底板外形候选

第一层装配验证显示 `270 mm` 长度前后窄边约 `10 mm`，对角部立柱和板材刚度偏紧。下一轮验证建议：

| 参数 | 优先候选 | 备选 | 说明 |
|---|---:|---:|---|
| 第一层长度 | 290 | 300 | `290 mm` 可将前后窄边提升到约 `20 mm`；`300 mm` 提升到约 `25 mm` |
| 第二层长度 | 290 | 300 | 初步跟随第一层，后续按开关尾部和线束调整 |
| 第二层宽度 | 208.4 | 待验证 | 初步跟随第一层轮胎外包宽度，不排除局部加宽 |
| 板厚 | 3 | 待验证 | 暂按第一层草案一致 |

---

## 3. 电驱下挂候选

优先验证两块双路电机驱动板安装在第二层底板下方：

1. 目标是释放第一层中部两侧空间。
2. 电驱应尽量靠近对应电机线束路径，减少动力线绕行。
3. 端子方向应便于电机线、主电源线和控制线分开固定。
4. 下挂高度需按电驱端子最高约 `11.6 mm`、垫柱高度、线束弯折和绝缘间隙共同验证。
5. 电驱下方不得与第一层电池、保险盒、线束、立柱或维护空间发生干涉。

备选方案：

1. 电驱安装在第一层底板下方。
2. 电驱仍安装在第一层上方但增加底板长度。

备选方案均需额外检查离地、防护、维护和线束风险。

---

## 4. 第二层上方硬件布局原则

第二层上方优先承载：

1. STM32 控制板。
2. Orin NX 与安装板。
3. Orin NX 独立 DC-DC。
4. 控制支路 DC-DC。
5. Mid360 独立 DC-DC。
6. 急停按钮和主电源开关。

布局原则：

1. 急停按钮和主电源开关放在尾部两侧，保证易触达。
2. Orin NX 保持散热和维护优先，不被线束和开关尾部遮挡。
3. STM32 靠近控制线束汇入区域，避免编码器线和 PWM/方向线过度绕行。
4. DC-DC 模块靠近对应负载和供电路径，但应避免高电流线束横穿控制信号区。
5. 线束应预留固定点和弯折半径，避免仅靠硬件端子承受拉力。

---

## 5. 立柱与层间空间

下一轮验证应优先检查：

1. 四角立柱孔位是否能落在前后加长后的实体区域内。
2. 立柱孔到板边、缺口边和硬件安装孔的距离是否足够，建议不小于 `8-10 mm`。
3. 层间高度是否能覆盖保险盒高度、第二层下挂电驱、线束弯折和维护空间。
4. 如果第二层下挂电驱，电驱与第一层保险盒 / 电池托盘之间应保留装配和散热间隙。
5. 如果使用亚克力板，需特别关注前后窄边、缺口圆角附近和立柱区域的抗晃能力。

---

## 6. 下一步需要确认

1. 第一层 / 第二层长度优先采用 `290 mm` 还是 `300 mm`。
2. 第二层宽度是否保持 `208.4 mm`，或是否为了开关、线束、立柱局部加宽。
3. 两块电驱下挂位置和端子方向。
4. 第二层上方各硬件初始摆放位置。
5. 层间高度初值。
6. 立柱孔位和数量。
