# 85 mm Wheel v0.1

状态：v0.1 单零件基线已归档，关键特征简化模型。

本目录用于保存 85 mm 天然橡胶轮胎的单零件 CAD 模型。该模型用于轮胎缺口、轮距、电机支架和联轴器装配关系验证，重点表达轮胎外径、宽度、轮毂外径和中心连接特征。

参数来源：

1. `hardware/cad/chassis_layer1/reference_drawings/轮胎.png`
2. `hardware/cad/chassis_layer1/design_inputs.md`
3. 用户手工 Fusion 360 建模与导出文件。

当前建模范围：

1. 轮胎外径：约 `Φ85 mm`。
2. 轮胎宽度：约 `33.4 mm`。
3. 轮毂外径：约 `Φ57.6 mm`。
4. 中心连接特征：按轮胎与联轴器装配验证需要建模。
5. 辐条、轮缘和轮面细节：按外观与装配识别需要简化建模。

暂不建模：

1. 橡胶胎纹的完整制造细节。
2. 轮胎材料弹性变形。
3. 真实装配公差、压缩量和动平衡影响。

归档文件：

1. `source/wheel_85mm_v0_1.f3d`：Fusion 360 可编辑源文件。
2. `final/wheel_85mm_v0_1.step`：已确认的 v0.1 单零件实体交换文件，后续装配优先使用。
3. `preview/wheel_85mm_v0_1.stl`：预览和快速尺寸检查文件。

验证记录：

1. STL 包围盒约为 `84.98 x 33.4 x 84.99 mm`。
2. STEP 文件单位为 mm，且包含实体 BREP，不是空导出文件。
3. STEP 中可识别 `R42.5`、`R28.8`、`R10` 等圆柱/圆特征，对应外径、轮毂和中心连接相关特征。
