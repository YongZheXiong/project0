# JGB37-520 Motor v0.1

状态：v0.1 单零件基线已归档，关键特征简化模型。

本目录用于保存 JGB37-520 带编码器减速电机的单零件 CAD 模型。该模型用于轮系装配验证，重点表达外包络、减速箱、电机主体、编码器占位、偏心输出轴和联轴器连接相关尺寸。

参数来源：

1. `hardware/cad/chassis_layer1/reference_drawings/电机.webp`
2. `hardware/cad/chassis_layer1/design_inputs.md`
3. 用户补充：减速比为 `70`，输出轴为 D 型轴。

当前建模范围：

1. 减速箱外径：约 `Φ37 mm`。
2. 减速箱 L 尺寸：`24 mm`，对应 `70` 减速比。
3. 后部电机主体：约 `Φ32 mm x 22 mm`。
4. 编码器部分：约 `Φ32 mm x 11 mm` 圆柱简化占位。
5. 输出轴：`Φ6 mm x 15 mm`，按减速箱偏心输出结构建模。
6. 输出端前凸台：按关键外包络简化建模。

暂不建模：

1. 编码器 PCB、排线、连接器和尾部细节。
2. 输出轴 D 面真实平面细节。
3. 电机端盖螺丝、通风槽、倒角和制造公差。

归档文件：

1. `source/jgb37_520_motor_v0_1.f3d`：Fusion 360 可编辑源文件。
2. `final/jgb37_520_motor_v0_1.step`：已确认的 v0.1 单零件实体交换文件，后续装配优先使用。
3. `preview/jgb37_520_motor_v0_1.stl`：预览和快速尺寸检查文件。

验证记录：

1. STL 包围盒约为 `37.0 x 78.0 x 37.0 mm`，轴向总范围包含输出端、减速箱、电机主体和编码器占位。
2. 侧面圆柱识别结果：减速箱约 `Φ37 x 24 mm`，后部电机主体约 `Φ32 x 22 mm`，编码器占位约 `Φ32 x 11 mm`。
3. 输出轴约 `Φ6 x 15 mm`，输出轴相对后部电机主体偏心，符合 JGB37 减速箱结构。
