# Hardware CAD Assets v0.1

状态：v0.1 单件 CAD 资产已归档，用于整车布局和空间验证。

本目录保存用户在 Fusion 360 中手工建模并导出的硬件单件 CAD 资产。当前批次用于第二层底板、下挂电驱、传感器安装、开关尾部空间、DC-DC 布局和整车干涉验证，不代表最终加工图、最终孔位或最终线束方案。

## 目录结构

每个资产目录统一采用：

1. `source/`
   - Fusion 360 可编辑源文件 `.f3d`。
2. `final/`
   - STEP 交换文件 `.step`，后续 Fusion 装配优先使用。
3. `preview/`
   - STL 预览文件 `.stl`，用于快速查看和包围盒检查。
4. `README.md`
   - 当前资产的来源、用途、尺寸检查和使用边界。

## 检查记录

1. 本批次 10 个资产均包含 `.f3d`、`.step` 和 `.stl` 三件套。
2. 所有 STEP 文件均检测到 mm 单位。
3. 除 D435 STEP 以 closed shell / 多壳体面模型形式导出外，其余 STEP 均检测到实体 BREP。
4. 所有 STL 文件均可读取三角面数量和包围盒，未发现空文件、英寸单位误导出或明显比例错误。
5. Orin NX 模型按用户实物裸板组合处理，尺寸约 `100 x 80.8 x 33.9 mm`；此前文档中的 `130 x 120 x 58.5 mm` 对应带外壳套件，不作为本次布局验证包络。

## 使用边界

1. 本目录优先服务 CAD 装配验证，不作为 BOM、采购状态或 DEC 事实源。
2. 单件模型未必包含完整制造细节、真实线束弯折、接插件插入深度、螺钉垫片高度和散热间隙。
3. 后续整车装配应优先引用各目录 `final/*.step`。
4. 若实物增加外壳、支架、风扇、固定柱、接线端子或线束保护件，应新增版本，而不是直接覆盖本批 v0.1 文件。
5. 第一层底板 `290 mm` 文件是布局验证草案；正式底盘 CAD 应在整车装配验证后另行收敛。
