# JD2912 Relay v0.1

1. 原始导出目录：`<本地CAD导出目录>/`

1. STL 三角面数量：`1682`。
2. STL 包围盒约为 `27.7 x 68.5 x 32.8 mm`。
3. STEP 单位为 mm。
4. STEP 检测到 `1` 个实体 BREP、`1` 个 closed shell 和 `51` 个 advanced face。

## 使用说明

1. 用于 JD2912 急停动力切断继电器的安装位置、端子朝向和动力线走线空间验证。
2. 当前模型不替代急停电路接线图、继电器触点容量校核和保险配置。
3. 后续装配应保证大电流端子有绝缘、防松和维护空间。
