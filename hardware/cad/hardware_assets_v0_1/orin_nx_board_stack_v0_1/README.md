# Orin NX Board Stack v0.1

状态：v0.1 单件 CAD 资产已归档，用于计算平台裸板组合空间验证。

## 文件

1. `source/orin_nx_board_stack_v0_1.f3d`：Fusion 360 可编辑源文件。
2. `final/orin_nx_board_stack_v0_1.step`：STEP 交换文件，后续装配优先使用。
3. `preview/orin_nx_board_stack_v0_1.stl`：STL 预览和包围盒检查文件。

## 来源

1. 原始导出目录：`<本地CAD导出目录>/`
2. 原始文件名前缀：`Orin NX_MODEL`
3. 建模方式：用户在 Fusion 360 中按实物组合整理并导出。

## 实物边界

本模型对应用户当前持有的 Orin NX 载板、核心板和 512GB 固态内存裸板组合，不包含外壳。此前仓库中曾记录过带外壳套件尺寸 `130 x 120 x 58.5 mm`，该尺寸不作为本模型的布局包络。

## 尺寸检查

1. STL 三角面数量：`253332`。
2. STL 包围盒约为 `100 x 80.765 x 33.895 mm`。
3. STEP 单位为 mm。
4. STEP 检测到 `180` 个实体 BREP、`161` 个 closed shell 和 `9930` 个 advanced face。

## 使用说明

1. 用于第二层计算平台摆放、散热空间、维护空间和线束接口避让验证。
2. 当前模型不包含外壳、额外风扇、上车固定板、线缆插头和线缆弯折半径。
3. 若后续增加外壳、风扇、保护罩或固定支架，应新增版本并重新验证第二层空间。
