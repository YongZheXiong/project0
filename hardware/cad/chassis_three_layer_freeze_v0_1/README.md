# Chassis Three Layer Freeze v0.1

状态：v0.1 最终冻结 CAD 包，用于当前三层底板加工输入、结构复查和后续实物装配对照。

本目录保存用户在 Fusion 360 中完成并导出的三层底盘最终冻结文件。源文件来自桌面目录 `<本地建模导出目录>/`，导出时间集中在 2026-06-02。

本冻结包承接本轮结构检查结果：用户已确认关键硬件尺寸、孔径、孔距、布局和必要优化处理；天线问题由用户另行解决；三层底板按铝合金加工沟通。该目录不替代 BOM、采购清单、DEC、架构文档或供应商加工确认单。

## 目录结构

1. `assemblies/`
   - 三层装配与整车装配文件。
2. `plates/`
   - 第一层、第二层、第三层底板单件文件。
3. `supports/`
   - Mid360 平台、Mid360 平台支柱、D435 支架、层间螺柱和电源托盘等必要支撑件。

每个资产目录统一采用：

1. `source/`
   - Fusion 360 源文件，`.f3d` 或 `.f3z`。
2. `final/`
   - STEP 交换文件，后续加工沟通和 CAD 装配优先使用。
3. `preview/`
   - STL 预览文件，用于快速查看、投影视图和包围盒检查。

## 加工与使用边界

1. 当前冻结包表示三层底板布局和整车架构已进入本轮加工基线，不表示底板已经加工完成、装车完成或验收完成。
2. 第一层、第二层、第三层底板按铝合金加工沟通；若 CAD 文件内部材料元数据与此不一致，应以供应商加工要求和人工确认为准。
3. STEP 文件优先用于加工沟通和后续装配复查，STL 仅作为预览和快速检查文件。
4. 本目录不承载天线最终位置事实；天线由用户按实物 SMA 座和小车两侧安装方案另行处理。
5. 本目录不记录线束完整路径、接插件插拔余量、扎带固定点、热缩管、垫片、螺丝长度或加工公差。
6. 实物装配前仍需复查大线走线、接插件可达性、散热间隙、急停可达性、电源开关操作空间和传感器视场遮挡。
7. 如后续改变底板孔位、层间高度、支撑件、传感器平台或整车架构，应新建版本目录和 CR，不直接覆盖本冻结包。
