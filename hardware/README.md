# Project0 硬件目录

> 当前边界：当前方案是 H60 V3.7 + 4×MC520 的两层单车系统；只有 H60 `PC0` VIN 电压采样，没有独立急停按钮、继电器、急停 GPIO 或车载电流采样。
> 现场状态：采购、到货、装车、接线、上电、刷写和运动状态以对应验收记录及本轮现场确认为准。

## 当前活动入口

| 路径 | 作用 |
| --- | --- |
| `bom.md` | 当前整车主件、状态与验证入口 |
| `cad/current_vehicle_v0_2/` | 当前唯一活动 CAD 库，共 28 个 STEP |
| `wiring/h60_power_wiring_v0_2.md` | 当前唯一接线设计入口；尚未实装 |
| `reference_docs/` | 当前硬件原厂文档入口；尚缺 H60 / MC520 可归档的官方手册 |

## 历史归档

`archive/` 统一保留上一辆 STM32/JGB/WSDC 小车的 CAD、线束、电源调试、图片与 P1.3 盘点文档；WSDC 数据手册未包含在当前公开快照。归档中的急停、继电器、ACS712、STM32、WSDC、六路保险盒和三层车体只是历史事实，不得作为当前采购、接线、固件或验收输入。

## 当前维护规则

1. 当前硬件边界变化必须先形成可追溯依据，再同步 BOM、CAD、接线与验收计划。
2. 只有实物和原始证据可以把状态从“待采购/待确认”改为“已到货/已实装/已验证”。
3. 当前线径、端子、支路保护定值与 UART 反灌防护仍须在 H2–H4 根据实物冻结。
4. 当前 CAD 已通过数字结构检查，但不替代实物尺寸、公差、试装、强度、散热、线束可达性和维护性验收。
