# Project0 当前整车 BOM

> 文档状态：正式 / P2 装车测试阶段主件台账
> 适用阶段：P2 及后续迭代一维护
> 最近收敛：2026-06-18
> 文件定位：记录当前整车采用的主要硬件、关键规格、装车状态和验证入口。

## 1. 维护边界

本 BOM 只记录会影响以下事项的硬件：

1. 系统功能和软件配置；
2. 电源、急停和运动安全；
3. 接口、接线和通信；
4. 结构安装和传感器位姿；
5. 故障定位、维修和替换。

以下内容不逐件纳入 BOM：

1. 通用螺丝、螺母、垫片、铜柱、尼龙柱；
2. 扎带、扎带座、线夹、标签和普通热缩管；
3. 杜邦端子、管型端子等通用耗材；
4. 电烙铁、万用表、示波器、热风枪和压线钳等工具。

上述小件按实际装车需要配置。涉及安全和复现的线径、保险规格、关键连接器和信号线仍在本 BOM 或 `hardware/wiring/` 中记录。

## 2. 状态口径

| 状态 | 含义 |
| --- | --- |
| 已装车 | 已安装到当前整车 |
| 已具备 | 硬件已在项目中，但不一定安装在当前车体 |
| 待复验 | 硬件存在，当前功能或装车状态需按 P2 清单复验 |
| 故障隔离 | 故障件不得继续作为有效主件使用 |
| 暂不采用 | 当前迭代不采购、不安装、不作为验收前置 |

到货、采购、供应商、价格和历史链接不在公开 BOM 中维护。

## 6. 后续维护规则

1. 新增主件、替换型号或移除当前采用件时更新本 BOM。
2. 普通耗材补货不更新本 BOM。
3. 测试是否通过不在 BOM 中展开，只更新状态摘要并链接原始记录。
4. 采购价格和链接不回填到 BOM。
5. 不以“硬件齐备”替代装车、通电、通信、传感器或运动验收。
