# Project0

Project0 是一个面向室内走廊场景的四轮差速移动机器人项目，由个人完成机械、电气、底层控制、ROS2 软件与系统验收。项目以真机为主线，目标是形成可验证的感知—决策—执行闭环，依次完成基础运动、定位建图、导航和最小语义任务，并以完整项目报告收束成果。

## 项目目标

- 在固定室内走廊中建立可复现的单车系统基线。
- 让底盘、传感器、计算平台和 ROS2 软件形成真实闭环。
- 以分阶段验收记录机械、电气、通信、控制、感知和导航结果。
- 保留代码、配置、CAD、接线、测试与失败证据，支持复现和复盘。

## 当前进展

截至 2026-09-05，项目处于 H60 + MC520 底盘重建阶段。Orin NX/C1902 在一次电气异常后已停止使用并送交专业维修；维修期间项目临时只推进 H60 能独立承接的基础运动子轨。

| 项目 | 当前状态 |
| --- | --- |
| 阶段与版本 | P2 / `v1.1-dev` / Unreleased；最新历史开发预发布 `v1.1-dev.2`，下一阶段性成果候选为 `v1.1.1` |
| 阶段门 | H0 已通过；H2/H3/H5 为 PARTIAL；H1/H4/H6-H8 未通过。基础运动和手柄控制尚未验收 |
| 机械 | 28 个当前整车 STEP 已完成数字复审；轮系、传感器支架和部分试装形成受限证据，最终固定、线束、热与动态回归未完成 |
| 固件 | 已同步 H60 默认安全固件、M1 运动控制实现、M2-A 单通道校准/慢驱工具及回归测试；默认构建仍为 `MOTION=0`，动力构建必须显式选择且不代表运动门已通过 |
| ROS2 | 已同步 H60 二进制协议桥、校准保持命令编码、手柄输入与安全仲裁的离线基线；Orin 不可用期间不声称完成 ROS2/实机联调 |
| 临时主线 | 依次完成 H60 本地运动安全设计、单轮/四轮架空、最低速落地的前进/后退/停止，再验证不依赖 Orin 的手柄接口与失联停车 |
| 历史平台 | STM32 + WSDC2412D + JGB37-520 + 三层底盘资料已归档 |

数字复审确认当前 CAD 的 28 个 STEP 均为有效 B-Rep，轴距为 `170 mm`、轮距约 `184.16 mm`，采用 6 根层间支柱，D435 水平安装。加工件到货后仍需按 H1 完成尺寸、孔位、平面度、连接器、风道、线束与维护空间的实物复核。

## 系统组成

| 子系统 | 当前方案 |
| --- | --- |
| 主计算 | Jetson Orin NX 16GB |
| 底层控制 | OpenCTR H60 V3.7 |
| 底盘 | 四轮差速，4 × MC520P56_12V，1:56，65 mm 橡胶轮 |
| 感知 | Livox Mid360 + Intel RealSense D435 |
| 供电 | 3S 电池 → 25A 主保险 → 主开关 → H60、Orin、Mid360 三条独立受保护支路 |
| 电压采样 | H60 `PC0` VIN ADC，多点校准后使用 |
| 通信目标 | Orin ↔ H60 版本化 UART 协议，带会话、序号、状态与故障语义 |

## 开发与验收

当前仓库提供 H60 架构、接线、默认运动锁定固件、受显式构建门保护的运动/单通道校准源码、二进制协议桥、CAD 和 H0-H8 验收基线。当前同步只表示源码与离线验证可供审阅；经 H5-H7 验收的动力运行固件仍在开发中。

Orin 维修期间的 H60-only 子轨不改变最终架构。既定手柄链是 USB 接收器接入 Orin 后经 ROS2/UART 下发；H60 是否能直接承接手柄输入仍为 `TBD / NOT RUN`，不会因临时目标调整而被写成已实现。

物理验证按以下顺序推进：

1. H0 到货与版本核对；
2. H1 不上电机械试装；
3. H2 断电电气检查；
4. H3 分支低能量上电；
5. H4 UART 单侧掉电与反向供电验证；
6. H5 固件故障注入；
7. H6 单通道电机与编码器；
8. H7 四轮架空与电源动态；
9. H8 受控场地落地低速。

当前停车与失能链由上电默认 `DISARMED`、显式 ARM、STOP/DISARM、通信超时、IWDG、异常撤 PWM、人工持续监护和主开关整车断电组成。车辆没有独立急停按钮、继电器或急停 GPIO；H8 仅在 H0-H7 全部通过、场地隔离、低速低加速度、主开关直接可达且操作者持续目视时执行。永久 UART 线束还需先完成任一侧掉电时的反向供电测量。
